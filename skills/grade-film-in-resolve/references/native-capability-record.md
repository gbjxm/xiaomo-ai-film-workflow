# 已记录的原生技术实测范围

记录日期：2026-09-16。环境：Windows，DaVinci Resolve Studio 20.3.0.10，本机官方脚本 API。此记录用于选择已有证据支持的操作；换版本、换桥接实现或处理不同对象时重新核对对应能力，不把历史实测直接当作当前连接成功。

## 已验证的范围

隔离技术试验使用一段 24 fps、120 帧、5 秒的时间线，原生渲染为 1280×720 的 H.264/AAC 文件。试验通过官方 API 应用 CDL 一级颜色调整并保存本地 Grade Version，再保存、重开工程、重新导出及恢复原版。

- 调整版与原版的解码视频 SHA-256 不同，说明此次颜色操作确实改变画面。
- 保存重开后的解码视频、音频 SHA-256 与此前调整版分别相同，支持本次工程保存/重开与 Grade Version 保持。
- 恢复原版后，解码视频、音频 SHA-256 与本次原版分别相同，支持此次本地调色版本恢复。
- 四个原生输出均为 120 视频帧、24 fps；音频在本次颜色操作前后保持一致。
- DRP 原生工程导出成功；尚未以该 DRP 重新导入并完成恢复回归，不能称 DRP 恢复链已验证。

这里比较的是解码媒体内容，不能改称四个封装文件字节相同。5 秒是技术测试范围，不取代用户要求的场景测试长度，也不是作品风格采用。

## 尚未由这次试验验证

LUT 应用、DRX 替换/恢复、Color 局部选区与窗口、跟踪、Fusion 质感、OFX 和其他插件各自需要单独验证。CDL 一级调整不包含这些能力；本地 Grade Version 成功也不证明能恢复任意节点图、整个工程或来自其他软件的迁移。

本次没有证明特定 Look 好看、肤色判断正确、显示器校准、跨镜匹配、动态局部稳定、完整剪辑保真、真实影片 QC 或用户正式采用。候选“自然柔和”或其他创作方向不继承本记录的技术通过状态。

## 当前版本的接口观察

这些观察仅描述该次调用条件，供技术层排错，不是专业调色参数：

- 任务 `JobStatus` 返回本地化的“完成”；不要只等待英文 `Complete`。结合实际任务状态、完成百分比、输出文件与回读判断，不因某一个字符串就声称画面正确。
- 向 `SetRenderSettings` 传入 `VideoQuality=12000` 的该次尝试返回 false。应检查实际可用设置与返回值；在不违反用户输出目标时可省略被拒绝的可选项，不能静默降低明确要求的交付规格。
- 该次 `AppendToTimeline` 使用 `endFrame=120`，实际得到 120 帧。以实际源、接口语义和时间线/输出帧数核对边界，不把这一样本外推为所有时间字段统一的闭区间或开区间规则。

## 回查定位与使用

原始证据随该次工作流维护报告保存，包含原生动作回执、媒体回读/解码哈希、四个对照输出和 DRP 工件；具体路径由维护报告提供，不在日常 Skill 内固定本机维护目录。需要重新执行或审计精确动作时读取对应回执，普通续调不反复加载维护历史。

本记录所支持的是官方脚本 API 路径。使用 `davinci-resolve-mcp` 或其他适配器时，还须确认其实际封装、错误处理与当前连接；不能因直接 API 试验成功，就声称任何 MCP 包装器已经端到端通过。
