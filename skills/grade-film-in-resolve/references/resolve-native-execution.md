# 原生执行与能力边界

本技能以可继续编辑的 Resolve 原生工程和真实原生渲染为执行事实。这里只定义核验与恢复方法，不假设任意版本/API/MCP 拥有全部 Color、Fusion 或渲染控制能力。

首次判断可执行范围时，参考[已记录的原生技术实测范围](native-capability-record.md)，再核对本机当前版本和本次动作。该记录支持已测链路，不是其他版本、所有节点或影片风格的能力承诺。

## 连接与证据

从本机实际安装或用户已配置的桥接入口发现 Resolve，不把作者机器安装路径写入脚本。读取当前版本、可用的官方脚本说明和桥接工具 schema；需要安装、启用或更改连接设置时按当次授权范围处理，不修改无关全局配置。

先只读连接，确认返回的是实际 Resolve 实例、当前工程与时间线。MCP 返回文字不自动证明其通过官方 API 控制软件；核对实现/说明和实际行为，排除隐藏的键鼠、快捷键或 Computer Use 操作。

按本次需要记录能力，避免为摸清所有接口反复扫全软件：

| 层级 | 所需证据 | 不足时怎样处理 |
|---|---|---|
| 连接与定位 | 实际版本、工程/时间线身份、只读获取成功 | 不猜目标，不写入 |
| 原生保存/恢复 | 保存或导出原生恢复点真实成功，位置/身份可核对 | 不执行节点替换或批量覆盖 |
| 源与项目设置 | 能读到的 Input、色彩管理、时间线/输出设置及未暴露项 | 未知保留；不按菜单印象编造 |
| 调色操作 | 具体 API/MCP 方法、参数定义、适用对象、返回值与读回 | 只执行已证实支持的范围 |
| Color/Fusion/效果 | 当前版本真实支持的节点、合成、工具/属性与处理位置 | 不从 GUI 功能推断接口全控 |
| 渲染 | 实际可用格式/编码、目标/范围设置、任务状态、输出文件 | 不能启动/完成则报告未导出 |

验证分清：文档列出 → 只读发现 → 隔离对象写入/读回 → 原生渲染 → 实际画面通过。只读发现或一次布尔成功不能跨级证明效果。

## 修改与恢复

若当前 Resolve 时间线来自其他剪辑软件导入或重新组装，先区分“已导入”与“保真已核对”：实际源和入出点、顺序、切点/时长、变速、裁切/重构图、已有画面处理及需要保持的音轨等，应按本次依赖对照原工程参考。未核对或存在差异时，不把它当成已经保真的正式时间线续调，不声称迁移完成；仍可继续用户明确授权、且不依赖未确认迁移结果的独立源素材小样。安装本技能或工具连接成功不授予项目迁移，也不替代保真比较。

1. 明确授权工程、时间线、目标片段和输出目录；检查离线媒体、帧率、画幅及需要保留的现有节点/合成。
2. 紧邻执行前重读目标相关状态。当前工程/时间线切换或出现未知修改时停止本次写入，不覆盖并发工作。
3. 普通续调在指定工程里完成。计划替换节点图、应用会覆盖现有调色的 DRX 或批量修改时，先保存并建立真实原生恢复点；记录恢复点类型、路径/标识和创建结果。
4. 原生工程导出或调色版本可否覆盖本次风险，须按实际能力判断。若只保存了部分 Grade，不能声称能恢复整个工程；若 DRX 的内容与覆盖方式未知，不在正式对象试错。
5. 优先对同工程中的隔离测试对象验证有风险的调用，并确认不会共享或连带修改正式剪辑对象的 Grade。无可靠隔离或恢复方法时，停止该危险调用，保留已完成的其他工作。
6. 记录本次可观察差量和读回；失败时按已验证恢复路径还原受影响范围，检查实际恢复状态，不能只执行撤销命令便宣称恢复完成。

恢复点不要求每次反馈都新建工程。其目的是防止不可恢复覆盖，不改变“同一工程持续调”的工作方式。没有必要恢复证据时不冒进，已有可靠恢复与授权时不另加重复确认。

## Color、DRX、LUT 与 Fusion

- 官方脚本 API 不等于 GUI 全功能遥控器。每个拟用的一级/二级调整、节点处理、参数读写、关键帧或跟踪步骤，都以当前方法可用性和实测为准。
- DRX 是调色交换/应用载体之一；其导入可能替换目标节点图或造成超出单参数的差量。先核对应用模式和实际影响，保留恢复点，不能把未知行为写成“追加一个节点”。
- LUT 表示颜色数值映射，不能携带空间窗口、遮罩跟踪、颗粒、降噪或其他依赖位置/时间的处理。保留 LUT 的输入、输出、应用位置与版本，排除双重变换。
- Fusion 可用性与 Color API 分开验证。只有当前原生 API 确认能创建/读取所需合成与工具、且适合本任务时才采用；不能为绕过接口缺口默认把所有调色重建为 Fusion 图。
- 对额外 OFX/Studio 功能、缓存、插件和 GPU 相关依赖，记录实际可用状态与原生渲染结果。节点存在不等于效果成功渲染；不假定软件版本或许可。
- 若只支持全局颜色映射而本片必须保护局部，明确局部项尚未完成并给出在已授权原生路径内的可行替代或具体限制；不悄悄转外部滤镜或键鼠自动化。

## 原生渲染与回读

按用户指定目标读取实际可用的渲染选项，设置本次输出范围、格式/编码、画幅、帧率和色彩相关项。不能以固定预设覆盖用户已有 Output Profile；未暴露设置须保留不确定性。

渲染前保存工程并核对输出位置；输出使用可追溯名称，不无授权覆盖既有正式文件。记录真实任务标识，轮询实际完成/失败状态，检查最终文件存在及可解码性。渲染队列已加入、状态完成和输出画面正确是三件事。

回读检查实际流信息和关键帧段；对照工程参考的相同源时点、裁切、显示路径和输出目标。检查全段运动与切点；不能仅凭首中尾静帧报告完整动态通过。需要时使用已有只读分析工具辅助，原生导出仍由 Resolve 执行。

当前任务不能通过后台接口完成时，交付已完成的工程状态、恢复指针、准确缺项和原因；不编造原生渲染，不修改用户工具偏好，也不自动增加新的远程服务或外部上传。
