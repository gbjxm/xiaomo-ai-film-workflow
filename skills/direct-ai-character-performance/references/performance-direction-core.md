## 表演设计的五层

```text
段落事件与关系变化
-> 角色目标、对象、阻力与代价
-> 刺激、行动、反应和结果组成的节拍
-> 身体、声音、空间和道具中的可见行为
-> 适配镜头与 AI 生成的首尾状态
```

### 1. 段落事件

先回答场景前后究竟有什么改变：关系、权力、信任、信息、承诺、决定或身体状态。表演必须服务这个变化，不为“有戏”而增加表情。

### 2. 目标、对象、阻力与代价

每个主要角色至少明确：

- **目标**：此刻想让什么发生。
- **对象**：试图影响谁或什么。
- **阻力**：什么正在阻止目标。
- **代价**：失败会失去什么，成功又可能付出什么。

目标应可在场景中追求。“想要幸福”通常过大；“让她留下”“逼他承认”“把钥匙拿回来”更可执行。

### 3. 行动动词

行动动词描述角色对对象做什么，而不是角色感觉什么：

```text
试探、安抚、诱导、回避、拖延、逼迫、拆穿、讨好、羞辱、压住、切断、保护
```

选择能改变对方的及物行动。一个节拍只保留一个主要行动；对方的反应或新信息使策略失效时再换动词。

“更悲伤”“更紧张”“演出愧疚”是结果指令。把它改写成条件和行为，例如“别让对方发现你在求他”“试图把颤抖的手藏在桌下”。

### 4. 表演节拍

最小节拍：

```text
刺激 -> 角色采取行动 -> 可见行为 -> 对方反应 -> 本轮结果 / 新刺激
```

节拍不按台词句号机械划分。以下变化通常触发新节拍：

- 新事实被发现。
- 对方拒绝、误解或反击。
- 目标或策略改变。
- 道具、空间或第三者改变局面。
- 角色做出决定或再也无法维持伪装。

### 5. 身体生活

身体生活是角色在追求目标时真正做的事，包括坐立、整理、寻找、清洗、挡路、藏物、保持距离和处理疼痛。它必须：

- 与情境和角色能力一致。
- 不抢走核心关系和信息。
- 能在镜头尺度中读出来。
- 有清楚的开始、过程和结果。

## 关系前态与后态

不要只写角色各自的情绪。记录他们如何互相定位：

```text
前态：谁掌控距离、信息、节奏或道具
变化：哪个刺激迫使谁改变策略
后态：谁获得或失去控制，关系如何重新命名
```

表演强度不等于声音更大或动作更多。关系权力可以通过不回答、延迟动作、占据出口、归还道具或停止照顾对方发生变化。

## 潜台词与秘密

潜台词本身不可直接生成。先区分：

- 角色知道但不说的事实。
- 角色对自己也不完全承认的需要。
- 角色希望对方相信的表面意图。
- 观众应知道或暂时不知道的信息。

再转成可见选择：说与做不一致、注意力回避、动作延迟、过度控制、突然改变距离或把道具当作关系媒介。

不要规定每一处微表情。尤其在 AI 生成中，过密的眨眼、嘴角、眉毛和手指清单会互相竞争，并产生机械表演。

## 工作版与备选

默认给出一个能贯穿全段的工作版解释。备选只在下列情况出现：

- 改变观众对角色真心或谎言的判断。
- 改变关系权力如何转移。
- 改变主要行动动词或动作因果。
- 改变对白和沉默的节奏骨架。

备选应说明收益、代价和会连带改变什么，不能只是“更克制 / 更激烈”的近义旋钮。

## 最低合格线

一个场景表演方案至少能回答：

- 每个角色想从谁那里得到什么？
- 什么刺激让角色换策略？
- 观众实际能看见或听见什么？
- 对方的行为如何改变了角色，而不是两个人各演各的？
- 场景结束时关系和身体状态怎样不同？
