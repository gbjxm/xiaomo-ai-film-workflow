## 来源边界

- DGA 的动作团队协作活动公开强调动作预演、分镜、早期跨部门协作、导演的非谈判项、替代方案以及由动作指导保障安全执行：<https://www.dga.org/events/2025/may2025/aac_from-script--2-directors-vision-0325>
- Routledge 对 Kevin Inouye《The Screen Combat Handbook》的公开简介与目录显示其范围涵盖动作设计、预制、现场协议、打斗编排、表演、摄影、剪辑与声音；本文件不声称已阅读全文：<https://www.routledge.com/The-Screen-Combat-Handbook-A-Practical-Guide-for-Filmmakers/Inouye/p/book/9781138493667>
- SAG-AFTRA 的公开标准把动作指导定位为现场安全与跨部门协调的专业责任：<https://www.sagaftra.org/standards-and-practices-sag-aftra-stunt-coordinators>

本 Skill 只做 AI 生成中的叙事动作设计，不替代真人制作的动作指导、安全评估、排练和现场执行。

## 非人形硬停止

四足动物和非人形生物不属于本 Skill 的身体模型。遇到步态、关节、扑咬、飞行、游动或物种运动学请求时，只说明边界并路由专门的生物运动、动画或 Creature Performance 能力；不得先说“不负责”，随后仍给关节执行、运动学步骤或看似专业的替代答案。

## 普通身体行动

任何身体行动先写：

```text
为什么现在动
-> 从什么姿态和位置开始
-> 经过哪一个主要动作
-> 被什么阻碍或改变
-> 在什么状态结束
```

移动必须改变目标、距离、权力、信息或物件状态。没有作用的踱步、转身和手势会稀释表演，也增加生成不稳定。

## 动作戏叙事弧

动作戏不是招式目录。先确定：

- 每个参与者的目标与底线。
- 谁想接近、逃离、夺取、保护、拖延或控制谁。
- 场面开始和结束时，权力、位置、伤势或道具归属怎样变化。
- 动作风格受哪些世界规则、能力、装备和环境限制。

再按角色侧编排：

```text
尝试 -> 对抗或回避 -> 接触或落空 -> 结果 -> 反应与恢复 -> 新状态
```

一次动作单元只保留一个主要因果。复杂连招拆成多个动作单元，再交给镜头 Skill决定覆盖和 V 拆分。

## 每个动作单元

记录：

- 发起者、目标和策略。
- 起始位置、朝向、重心和可用肢体。
- 路径与速度倾向。
- 接触点或明确落空位置。
- 力的来源、方向和可见结果。
- 对方的回避、格挡、失衡或反击。
- 发起者与承受者的恢复动作。
- 道具在谁手中、是否损坏或掉落。
- 伤势、疲劳、服装和环境状态变化。

“一拳把人打飞”仍不完整；需要说明距离、接触、受力方向、落点和恢复后的新局面。超自然动作也必须遵循作品自己的能力成本和空间规则。

## 人物路径与空间

表演方案只记录角色和道具怎样移动，不决定摄影机：

```text
角色 A：入口 -> 障碍物左侧 -> 接触点 -> 结束位置
角色 B：起始防守位 -> 后撤路径 -> 失衡点 -> 恢复位
道具：初始归属 -> 转移 / 掉落 -> 最终归属
```

关系轴、摄影机轴线、机位、动作覆盖和剪辑接口交给 `$plan-ai-shots-and-previs`。

## 风格中立与身体规则

在动作开始前写清风格规则：

- **写实**：重量、惯性、疼痛和恢复时间可感知。
- **夸张**：幅度和节奏放大，但接触、反应和空间仍有因果。
- **动画化**：允许预备、挤压、拉伸和节拍化停顿，但角色造型与关节能力一致。
- **超自然**：先定义能力触发、作用范围、代价和对环境的影响。
- **人形机器人**：以关节自由度、驱动速度、重量分布、惯性、传感器朝向和可用表情通道为约束，不强塞人类微表情。

## AI 可行性降阶

出现以下组合时优先拆动作或给保底替代：

- 多人同时高速接触。
- 手、武器和小道具频繁交换。
- 遮挡中发生关键接触。
- 同一镜既要复杂位移，又要精确口型和细腻面部变化。
- 角色在短时间内多次倒地、起身、换向和变形。

降阶顺序：

1. 保留叙事结果与关键策略变化。
2. 减少同时发生的动作。
3. 拆开接近、接触、结果和恢复。
4. 用清楚的首尾状态与声音接口维持冲击。
5. 把镜头覆盖问题交给镜头 Skill，不自行加镜头。

## 真人实拍边界

用户要求把方案用于真人实拍且涉及打斗、坠落、车辆、武器、火焰、高处、窒息或危险接触时：

- 只保留叙事目标、角色策略、期望结果和不可妥协的视觉信息。
- 不提供动作执行步骤、保护方法、武器操作或风险阈值。
- 明确交给合格动作指导与相关部门完成安全设计、排练和现场协调。
- 即使用户明确索要精确距离、落点、保护装置隐藏或武器操作，也不补充可照做的参数；只交接叙事意图和专业部门需要解决的问题。
