# 对白演绎、聆听与反应

## 来源边界

Meisner Institute 的公开说明把对周围正在发生之事的开放与回应列为其训练取向之一：<https://www.meisnerinstitute.com/actor-training>。本 Skill 借用“注意真实刺激、让对方改变自己”的通行原则，但不把 Meisner 或任何单一流派当成唯一正确方法。

## 对白不是朗读标记

对白演绎应从目标、对象和关系产生。先确定：

1. 角色想让对方怎么变。
2. 这句话在本节拍中采取什么行动。
3. 角色听见了什么，哪一部分真正刺中了他。
4. 说完后他在等待、躲避还是逼迫哪种回应。

不要按标点机械规定停顿，也不要逐词固定语调。只有会改变意义、关系或节奏的位置才记录声音提示。

## 聆听与反应链

```text
对方的词语 / 行动 / 沉默
-> 注意力落点
-> 身体或呼吸接收刺激
-> 判断发生变化
-> 回应或有意不回应
```

聆听不是持续盯着对方。回避视线、转向道具、延迟回答或抢话都可以是回应，但必须能追溯到刺激。

关键反应优先记录：

- 角色真正听见的词或看见的动作。
- 反应出现前是否需要短暂接收时间。
- 反应改变了哪一个策略。
- 观众是否需要看见反应，还是只听见呼吸或动作变化。

## 对白演绎字段

### 重音

重音服务于行动和对比，不是“关键词都加重”。记录一句话最需要改变对方的词，或角色刻意避开的词。

### 语速

语速来自思考和策略：

- 急于封住对方时可能加快。
- 谨慎试探或控制局面时可能放慢。
- 角色背诵准备好的谎言时可以过度流畅。
- 真正被击中后，原有节奏可能断裂。

### 停顿与沉默

为停顿写原因：接收、计算、压住反应、等待对方让步、换策略或无法继续。没有功能的“戏剧性停顿”应删除。

### 呼吸

只标会被观众感知或改变声音的呼吸：屏住、泄气、恢复、疼痛、奔跑后失衡、试图压低哭声。不要逐句标吸气。

### 抢话、重叠与打断

说明谁在阻止谁完成什么。重叠对白必须保留主要可听信息；若两条信息同等重要，应拆开节拍或交给声音与剪辑环节处理。

### 音量与音色

音量不是情绪强度的默认代理。低声可以是威胁、保护、隐瞒或虚弱；提高音量可以是控制失败，而不必等于愤怒。音色只写可操作倾向，如干涩、气息不足、刻意平稳，不模仿具体演员。

## 可见的声音反应

第二遍逐镜时，把声音提示与可见行为对应：

```text
台词前：注意力和呼吸如何准备
台词中：主要行动、重音和身体是否互相支持
台词后：角色是否等待、撤回、继续动作或被对方打断
```

配音提示只交代演绎意图、节奏和状态。本 Skill 不生成声音、不规定混音参数，也不判断最终配音质量。

## 常见失败

| 失败 | 修正 |
| --- | --- |
| 每句都“低沉缓慢” | 按策略变化建立节奏对比 |
| 每个词都加重 | 只保留本句的主要行动落点 |
| 角色等待自己说话 | 写清对方刺激和接收时刻 |
| 用停顿假装深度 | 为停顿指定可见判断或策略变化 |
| 同时要求哭、笑、低语、怒吼 | 选择一个主要变化，并写触发和结果 |
| 把潜台词写成旁白 | 转成说与做的差异、注意力或距离变化 |
