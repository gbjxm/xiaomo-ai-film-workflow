## 核心转换

生成模型不能直接执行“潜台词”“复杂心理”或“演技高级”。把它们转成可见、有限、连续的信号：

```text
心理与关系意图
-> 一个主要行动动词
-> 一个可见动作单元
-> 清楚的刺激与注意对象
-> 可验证的开始 / 结束状态
```

本文件保持模型无关，不预设时长、分辨率、口型或参数上限。具体模型能力由 C 在生产时判断。

## 单镜动作预算

每个 V 镜头优先只保留一个主要表演变化。可以包含相邻的简单动作，但避免同时要求：

- 大幅走位。
- 精确手部或道具接触。
- 多人复杂反应。
- 细腻面部转变。
- 长对白与严格口型。
- 摄影机复杂运动。

若这些任务竞争，先保留镜头叙事功能和表演因果，再给最小替代；不得自行改变 V 功能。

## 可见尺度与景别适配

| 既有景别 | 优先可见表演 | 不宜依赖 |
| --- | --- | --- |
| 远景 / 全景 | 位移、姿态、人物距离、动作轮廓 | 细小眼神和嘴角变化 |
| 中远景 / 中景 | 重心、手势、道具、接近与回避 | 过密微表情 |
| 中近景 | 视线、呼吸、头肩变化、克制手部动作 | 大范围走位 |
| 近景 / 特写 | 注意力、接收刺激、细微呼吸和面部变化 | 多人物复杂空间行为 |

如果关键行为在当前景别不可见，返回镜头 Skill说明冲突；不能偷偷把镜头改成近景。

## 开始与结束状态

每镜至少记录：

- 人物位置、朝向、姿态和重心。
- 视线与注意对象。
- 手部与道具状态。
- 与他人的距离或接触状态。
- 呼吸、伤势、疲劳和服装异常。
- 本镜结束后下一镜必须继承的变化。

跨镜只锁定观众能识别且影响因果的锚点，不追踪无价值的手指角度等噪声。

## 人形机器人

先确认：

- 关节范围与运动速度。
- 重量、惯性和制动方式。
- 视觉、听觉或传感器的注意方向。
- 面部、灯光、屏幕或声音中可用的表达通道。
- 是否模仿人类动作，以及模仿的不完整之处是否有叙事意义。

把“犹豫”转成传感器重新对焦、动作中止、执行延迟或关节预备状态；不要默认使用眨眼、吞咽等不存在的生理动作。

## 对白与口型

把对白演绎和口型生成分开：

- 本 Skill记录意图、重音、速度、停顿、呼吸、打断和可见反应。
- 图片由 `$format-gpt-image-2-prompt`、Seedance 2 视频由 `$format-seedance-2-prompt` 将已确认信息忠实整理为目标模型表达。
- C 决定是否同期生成、后期配音或采用无口型方案。
- D 完成真实配音、声音和剪辑判断。

若长对白与复杂动作同时出现，最小替代可以是缩短可见台词、把部分对白移为画外声或减少动作，但任何台词事实变化都必须由用户或 B 确认。

## 结构化交接块

每个 V 向对应模型格式器传递：

```text
角色与当前状态：
表演目标 / 行动动词：
刺激与注意对象：
可见动作：起点 / 过程 / 终点
身体与视线：
人物距离 / 接触 / 道具：
对白演绎与可见声音反应：
结束状态与连续性锚点：
禁止偏移：
AI 风险与最小替代：
```

交接块不包含镜头参数、风格堆词、模型参数、负向词或最终提示词。镜头信息来自对应 V 方案。

## 风险与最小替代

风险必须具体到失败机制：手部接触错位、多人身份交换、动作因果不清、细节在景别中不可见、首尾状态不稳定等。

最小替代遵循：

1. 不改变剧本事实。
2. 不改变已采用的场景表演主线。
3. 不改变 V 的镜头功能。
4. 只减少同时任务、动作精度或不可见细节。
5. 无法满足前三项时返回相应岗位，而不是伪装成可执行方案。
