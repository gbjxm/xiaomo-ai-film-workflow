# 生成视频整理与取用

把用户指定的一批完整生成原片组织为“片段 → 多条原片 → 每条的可用区间”，使文件好找、结果好比较、来源可回查。一个片段可包含多个镜头，一条原片可贡献多个不连续区间；同一最终片段可以同时取用几条原片。沿用当前媒体目录，不重新设计工作流。

## 先选择本次最轻动作

- 只讨论或查看：只给建议或查询已有索引，不复制媒体、不计算全素材树哈希。
- 用户要求整理明确的一批新下载视频：读取点名文件和必要片段说明；已明确“尚未导入剪映”的信息可用于整批，不逐文件重复问。准备并展示简短归位结果，在该授权内一次执行完整文件复制和登记，不额外索取同一授权。
- 已导入工程或状态不明：只登记/查找原位置，不移动、改名、覆盖或让剪辑软件自动换源。不能通过文件名、所在目录或修改时间猜是否已导入。
- 记录选段：只记录用户指出、已有 C/D 记录提供或本次实际审看得到的区间；没有评价可以只归位，不要求看片、标完区间后才导入。
- 找素材：按片段、内容、Aroll/Broll/其他素材筛选，返回原文件、源时间和必要限制。用户需要时打开准确所在目录以便选择文件；不把输出清单称为已导入剪映或已经剪辑。

只有片段归属不清且会导致错误放置时，问一个关键问题；其他未确定内容留空。不要让用户填写 JSON、UUID、哈希、完整台账或全部技术参数。

## 目录、命名与原件

先读项目 `开始这里.md`，按其媒体/资料布局定位。媒体标识必须是 `media-layout-v1` 或 `media-layout-v2`；无标识项目只给建议，不自动迁移。helper 读取现有创建技能与统筹技能的共享布局定义，不另建目录规则。

新视频放在 `02_视频/<Aroll|Broll|其他素材>/<片段名>/`，同一片段的多条完整原片直接并列，不再为每条、每一代创建多层文件夹。默认文件名为 `<片段名>_生成01.<原扩展名>`；片段名优先使用已有场次及可读内容，如 `S06_到公司核对`。没有正式编号就用片段名，不补造 S/A/V/CUT/PUB。文件序号和索引内部键只识别文件，不表示镜头号、剪辑顺序、生成质量或采用状态。

只有明确未导入的新增文件才复制归位，下载原件保留。重复文件按字节 hash 判断，同片段同类别可复用已归位原片；同名不同内容保留为不同文件，跨片段不擅自合并用途，不删除任何原下载。相同提示词或相似画面不是重复证据。

名字不带“最佳、已用、最终”等变化评价。状态变化、切点变化和剪辑重排不触发重新命名或搬文件。代理、转码、稳像、修复件若存在，必须保留源关系；首版不会生成这些处理件，也不将它们冒称新的完整生成原片。

## 可用区间只记有价值的信息

区间必须绑定精确原文件；按**原文件时间**记录整数毫秒。时间线位置是另一类信息，不覆盖源入/出点。允许同一文件有多个区间；区间内容重叠可能是不同候选取法，不强行合并。

面向用户通常只展示：文件、源入点—出点、内容/用途、关键限制。备注按需包含“画面可用但原声不用”、内部换镜、动作首尾状态、视线方向等实际衔接条件。只有有据时记录，不能从文件名猜质量、动作或精确时码。用户只说“中间停步好”时先记未定位备注，核对实际媒体后再落精确区间。

每个精确区间保留简短意见出处（用户明确描述、既有 C/D 记录路径，或本次实际审看说明）。helper 只校验时间格式及已知时长边界，不判断艺术可用性。时长未知时明确标“边界未核验”，不得冒充可播放、已审看或可直接拼接。

保留完整原片，让用户在剪映里调整切点和前后余量。第一版不预导出大量选段文件，不自动生成串剪、修改时间线或写剪映内部草稿。是否能直接把索引转换为软件标记/子片段，要另核实实际软件版本、界面和工具，不预先承诺。

## 机械索引与专业记录

仅维护一个机械索引：资料布局启用时为 `90_制作资料/生成记录/素材整理/素材索引.json`，未收拢资料但媒体布局已启用时为 `生成记录/素材整理/素材索引.json`。此子目录由本 Skill 独占机械维护；不预建空索引，也不把同一内容再复制成长期 Markdown/CSV 台账。用户看的简短表从索引按本次问题生成。

优先复用已有 C 的片段、生成来源和审查意见，以及 D 的真实使用记录；只补缺失的文件定位与区间。索引是查找辅助，不是正式 C 生成记录、准入、D 接管/CUT/素材使用表或采用索引。它不走 Adopt 变成创作采用，也不改任何岗位主文件、已有 C/D 记录或 `.工作室/采用索引.json`。C 的推荐与 D 的实际使用分别引用，不合并成一个“最终版”。

本 Skill 只复制既有完整文件和保存技术索引，不生成、转码、剪切、修复、混音、上传或发布；`media_execution` 保持原值。已被工程引用的旧路径缺失时报告确切缺口，不按同名文件、修改日期或相似内容自动换源。

## 工具执行

只有实际归位、登记、记录区间或检索时才读取 [CLI 用法](references/cli.md)，调用 `scripts/media_catalog.py`。prepare/list 不创建项目文件；需要落实时由助手保存计划并 apply，具体源文件和索引的 hash 用于这次写入核对，不要求用户手工提供。中断后优先复用已保存计划；先确认返回的部分完成范围，再按原计划恢复，不重新给相同素材另分名字。

set-ranges 必须基于刚读取的对应文件记录和索引版本合并用户差量，保留未点名区间；调用该动作提交该文件完整范围集。不得用一条新增意见清空其他区间。后来取得时长时，可同时补充时长及其真实出处，并重检本条完整区间；不能为使越界区间通过而编造时长。毫秒只是记录精度，不代表切点已逐帧验证。源文件或索引漂移时停止本次写入、重新读取，不覆盖变化。

工具不可用或没有真实文件时，交付能执行的归位/命名/选段建议并说明尚未执行。只有复制和索引回执真实完成才报告已整理；占位文件测试、哈希一致和数学边界校验都不证明真实可用区间或剪辑效果。

## 交付

简要说明本批新增归位多少、重复复用多少、原位登记多少；给可直接打开的片段目录或真实文件路径。选段只列当前需要的一组，并指出未定位/未核验项。不要向用户复述内部 JSON/锁/哈希协议，也不强制逐条审片或填满表格。完成当前批次后等用户实际使用反馈，不自动整理整个磁盘或相邻项目。
