## 1. 对象与坐标

稳定影视对象只使用 `Sxx/Axx/Vxx/CUTxx/PUBxx`。`Setup`、batch、take、场景卡、交接清单都是版本、执行坐标或证据文件，不分配新稳定 ID。

- Setup 显示名称：`Vxx Setup vNN`。
- Setup 文件内执行键：`Vxx_Setup_vNN`。
- take：`Vxx-Bnn-Tnn`，其中 B 是真实生成批次，T 是该批次内真实输出。
- 场景卡：每个 `Sxx` 唯一 `场景制作/Sxx_场景制作卡.md`，内容按 `vNN` 升版。
- C 清单：`场景制作/C交D素材清单_vNN.md`。

## 2. Vxx Setup vNN

每个 Setup 必须原子绑定以下字段；每个文件型输入都写精确版本、项目内路径和 SHA-256，不用“最新版”“见上文”或聊天记忆代替：

1. `Sxx`：采用版本、路径、SHA-256。
2. 场景导演基准：场景卡版本、路径、SHA-256。
3. `Axx`：每个必要资产的 ID、采用版本、路径、SHA-256；没有必要资产时写不适用理由。
4. 采用色卡与项目视觉弧线：精确版本、路径、SHA-256；没有专项色卡时仍引用项目视觉弧线。
5. 表演与调度：采用版本、路径、SHA-256；无人表演时写不适用理由。
6. `Vxx` 镜头方案：采用版本、路径、SHA-256。
7. 实际输入文件：逐项写绝对路径或可从项目根唯一解析的路径、SHA-256、用途；缺文件或 hash 不符即不就绪。
8. 后期接口：默认 Output Profile 的名称与版本，或条件性 D 后期预设的版本、路径、SHA-256。风险触发但预设未完成时不就绪。
9. 工具/模型限制：目标工具、已知能力边界、输入数量/格式等当前限制和最低替代。
10. 输出规格：媒体类型、画幅/分辨率、时长、帧率、色彩/编码要求、文件命名和把手目标；未知项明确标出。
11. 声音/口型/剪辑接口：只写声音事件、口型同步需求、切点/把手/画外信息和可见反应，不制作最终声音。
12. 未解决项：问题、影响、责任人和解除条件；没有时写“无”。
13. 执行有效性、判定时间、判定依据与当前适用的提示词卡。

一个 Setup 只能引用一组当前采用版本。候选、停用、旧版和当前版不得混入同一 Setup。

## 3. 就绪与失效

Setup 就绪必须同时满足：

- 13 组字段齐全且可唯一解析；
- 所有上游持久状态为采用，文件存在且 hash 匹配；
- 专业约束之间无未裁决冲突；
- 风险触发的 D 后期预设已经在首个受影响 Setup 前完成；
- 所有未解决项都不阻塞生成。

执行有效性使用：

- `未触发`：尚未开始汇合；
- `进行中`：仍缺字段或等待专业输入；
- `已冻结`：本版精确输入齐全且无冲突；
- `已失效`：任一锁定输入版本、路径、hash、Profile、限制或规格变化；
- `不适用＋原因`：该 V 不进入生成。

上游变化后：

1. 保留旧 Setup、提示词卡和真实 take 作为历史；
2. 把旧 Setup 标为已失效，提示词适用性和相关 take 准入结论标待复核；
3. 只为受影响的 `Vxx` 建新 Setup 版本；
4. 只有实际被新版本重新核验的 take 才恢复当前准入。

Setup 冻结只允许进入格式化判断，不等于提示词已采用，更不等于已授权生成。

## 4. 逐 take 接口

每个真实 `Vxx-Bnn-Tnn` 至少提供：

- 所属 `Vxx`、Setup、提示词卡与生成记录的精确版本；
- 真实文件路径与 SHA-256；
- 工具、模型、批次、实际输入和实际参数；
- 时长、帧率、分辨率/编码、音轨；
- 首尾把手与开始/结束状态；
- 动作、反应、空间和声音接口；
- 与计划的实际差异、已知限制、单文件技术可用性；
- C 准入：`推荐 / 备选 / 停用`，以及可定位理由。

C 的推荐不等于 D 必须入片。D 不得静默使用停用 take；确需使用时经 A 返回 C 复核并保留决定证据。

## 5. 功能化 coverage

coverage owed 只按实际缺失功能描述，可选类别：

- 叙事信息或关系变化；
- 关键反应；
- 动作的开始、过程、接触、结果或恢复阶段；
- 空间基准、屏幕方向或入口出口；
- 必要插入/道具状态；
- 声音、口型、画外信息或剪辑把手接口。

每项必须写 `发生于 S/V / 缺失功能 / 现有素材为何不可替代 / 最近责任站 / 所需证据 / 状态`。禁止只写“缺近景”“多来几条”“重做”“coverage 不够”。

## 6. C 交 D 素材清单

清单由 C 独占，A 只保存当前有效路径、版本和 hash。至少绑定：

- 精确 `S/A/V` 版本；
- 场景制作卡、Setup、提示词卡、生成记录的版本/路径/hash；
- 推荐、备选、停用 take；
- 每个 take 的路径、SHA-256、时长、帧率、音轨和批次；
- 首尾把手、动作/反应/空间/声音接口；
- 实际差异、已知限制和 C 准入理由；
- 当前按计划仍欠的功能化 coverage。

清单结论只能写“当前 C 准入自检通过，可交 D 组接候选”或“阻塞，暂不可交 D＋原因”。不能证明实际可剪，也不能分配 CUT。

## 7. D 返回 C 的最小返修

D 经 A 返回时必须给：

```text
CUT 时间点：
Sxx / Vxx：
功能性缺口：
现有素材不可替代原因：
最小责任站：
返回依据：
期望补齐接口：
```

最小责任站只选：场景导演、生产设计与资产、表演与调度、摄影灯光与镜头、数字拍摄与生成、场记审查与交接。只返最近责任站；功能不变保留 V 并升 Setup/take，功能改变才停用旧 V、新建 V。
