# 封面验收契约

## 必需证据

| 维度 | 通过条件 |
| --- | --- |
| 来源 | 记录采用 `CUTxx vNN`、精确 Master 版本/路径/hash/Profile 与来源时间点，或已采用资产路径；生成或编辑动作有明确授权 |
| 真实性 | 角色、场景、冲突和结果均能由成片或合法来源资产支持 |
| 表达 | 单一主视觉，标题与封面表达同一观看承诺 |
| 缩略图 | 缩小后主体仍可辨，主文字仍可读，没有无意义的小字堆叠 |
| 裁切 | 关键主体、文字和标识处于目标平台可见安全区 |
| 文件 | 路径真实、可打开，尺寸与格式可核验，版本不覆盖旧文件 |
| 权利 | 字体、图片、肖像、商标和其他外部素材来源与授权状态明确 |

## 不能通过

- 只有方向、提示词或效果预想，没有最终文件。
- 封面承诺成片里不存在的情节、人物、奖项、数据或结果。
- 文件打不开、文字错误、比例不适用、关键主体被裁切或来源不明。
- 需要重做影片核心视觉，却被当作普通封面修改留在 E。
- 只有 CUT、代理/参考/旧导出，或缺少 Master SHA-256、Output Profile、组件绑定。
- 平台需要视频新画幅、重编码、字幕版、音轨版或修复，却由 E 自行修改 Master。

Master 路径、版本、SHA-256、Output Profile 或绑定组件变化时，旧来源结论失效或待复核；重新审看新 Master 后才可确认封面继续适用。

平台规格会变化；只记录当次官方来源和核验日期，不把参数固化为永久规则。
