# V0.9 封面视觉候选咨询

先完成主文版本路由。前期可按作品与传播承诺讨论封面意图，不要求先有 QC Master；不把该候选当成可发布封面。

- 提出一个有内容依据的主视觉、文字层级、缩略图观看重点和素材需求，说明该画面在作品中是否已存在、仍属设计候选或需要成片选帧确认。没有真实图片时只交文字方案，不虚构图片编号、截图或选帧时间点。
- 已有点名参考图时仅分析其真实可见内容和职责；不把资产设定图当成已采用成片帧，不为点击创造作品中没有的角色、冲突或结果。平台尺寸、安全区和版权条件仍须依原专业要求核验。
- 返回视觉候选及待核实的素材来源；不在本批抽帧、裁切、排字改图、生成封面或声明媒体验收通过。正式制作仍需主文的精确 Master/组件基线、来源核验及独立媒体授权，并受共同能力门限制。
- 封面构想需要改影片内容时交 C1/C2/B 提候选，不修改 Master。候选按实际能力 SaveDraft；用户明确采用的文字设计通过所属 E 事务 Adopt，已采用输入先 Resolve。能力关闭时只保留演练决定，不调用旧写回冒充同步；文本保存不代表封面已制作。

## 新素材目录的封面路径

项目入口明确声明 `workflowMediaLayout: media-layout-v1` 或 `workflowMediaLayout: media-layout-v2` 时，新封面图片使用项目内 `01_图片/封面/`，v1 需要真实保存时才建立，v2 在创建项目时预建；正式封面文件命名仍为 `PUBxx_封面_vNN.<ext>`。本条仅将主文的新封面媒体路径由 `assets/封面/` 切换到该入口，记录所有权、精确 Master 绑定、采用和执行边界不变。已有封面继续引用真实旧路径，不自动搬迁或重绑。无此标识的项目仍用原路径，不据机器安装版本启用。
