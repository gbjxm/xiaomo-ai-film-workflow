# V0.9 C1 美术与资产候选

遵循共同契约的候选和能力边界。本分支无需先有采用 Sxx/Axx；从现有故事、C2 导演基准、当前完整工作稿和精确点名参考提出本轮设计。专业事实层级、尺度、材质、空间与状态定义按需读 [资产规格契约](asset-spec-contract.md)，不执行其正式编号或写回步骤。

项目图片的首次实质建议、编写与局部修改，执行 [图片任务的视觉基准核对](../../direct-ai-scene-production/references/studio-v09-candidate.md#图片任务的视觉基准核对)。仅读该小节并由当前 C1 完成，不加载 C2 其余流程；独立图片支线同样适用。

## 和导演共同确定可用资产

先接收 C2 的叙事功能、观众第一眼需要辨认什么、人物调度与镜头观察需求。缺少可见细节时提出推荐设计及理由；若设计将改变故事地点、事件结果或人物身份，列为故事候选差量并交 C2/B 对齐。不要等全套资产画完再请导演判断能否使用。

每项候选保留原有明确不变量，说明形态、材质/本色、尺度、可变项、与其他对象的关系以及验收重点。场景优先明确出入口、通路/障碍、层次、共同参照、可用光源和至少能承载当前动作的空间关系；只画“好看背景”不算解决场景任务。

## 三种用途分别设计

| 用途 | 本轮应确定 | 不得自动继承到后续镜头 |
| --- | --- | --- |
| 基础资产 | 人物身份、体型、服化道本色；场景几何、材质、出入口、光源条件；道具形态和用途 | 定妆背景、展示姿态、展示机位和为辨认资产使用的中性光 |
| 状态资产 | 同一对象在本段前后发生的发型、服装、损伤、污渍、道具归属或环境变化 | 未发生的下一状态；另一个人物或时间点的状态 |
| 镜头参考 | C2 已给出的本镜机位/构图、活动状态、光影和动作起止所需图像 | 对其他镜头的同机位、同构图或同 Look 限制 |

基础资产以可靠识别和复用为目的，不强制所有艺术设计都无色或无风格；有明确中性展示用途时，才用中性环境观察本色。镜头参考须承接 C2 视听方案，C1 不借生图改写表演或新增机位决策。

同一对象的多个候选仍可比较；同一镜头实际使用哪一个基础/状态参考必须明确。采用资产只引用当前有效版本，候选替代不得覆盖它。C1 与 C2 共用该引用，不复制成两份“采用资产库”。

## 真实参考与制作需求

对已看过的参考写出实际能证明的身份、结构、材质和状态；遮挡、画外空间及推测另列。对未提供的素材写“待制作/待提供”，不要分配外部图片标记或把文字设计说成已有图片。

配色由 `$cinematic-palette-architect` 返回本色/状态/镜头显示的相应候选；最终图片复制文本由 C1 明确调用 `$format-gpt-image-2-prompt` 忠实编排。本专业交给 C2 的是具体设计、允许和禁止继承、冲突、待制作素材及当前版本，不是仅有资产名的清单。

交付前核查：场景能否容纳指定路径和视线；尺度与材质是否可信；状态变化是否保留身份；基础展示条件是否污染镜头；候选图与真实已有参考是否区分。真实图片的结果检查使用媒体 Skill 的资产分支；候选不分配正式 Axx。按实际能力通过 SaveDraft 保存候选；用户明确采用后由 C1 提供完整专业文本经 Adopt 提交，已采用资产经 Resolve 取得。关闭能力时只保留演练决定；本批不生成媒体或覆盖 C 总索引。
