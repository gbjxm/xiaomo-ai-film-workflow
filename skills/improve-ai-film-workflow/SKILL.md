# 影视工作流自我迭代

管理“记录 → 复盘 → 用户选择 → 修改 → 归档”的完整生命周期。项目岗位只调用记录模式；总工作流维护任务才可调用维护模式。

## 日志目录路由

入口显式声明 `workflowDocsLayout: production-docs-v1` 的 v0.9 项目，流程日志位于 `90_制作资料/流程改进日志/`；无标识项目保持原根目录。三个脚本按入口与共享路径定义定位，不按文件夹存在猜版本。下文逻辑日志路径在新布局使用此前缀，证据仍相对整个项目根。记录、扫描与归档的原授权和所有权边界不变；迁移目录不授权创建或处理 WFI。

## 模式判断

### 项目记录模式

当当前目录位于影视项目中，且已观察到以下流程问题时使用：重复返工、遗漏、交接失败、职责冲突、重复手工步骤、工具失败、证据缺口、契约不清。

不要记录正常的剧情、人物、镜头、提示词或文案迭代。不要把猜测写成事实。普通问题静默登记后继续当前任务；只有问题已经阻塞任务，或涉及覆盖、数据丢失、权限和安全风险时，才在当前回复中同时报告。

1. 读取项目 `开始这里.md`，确认日志契约和当前岗位。
2. 把事实、影响、证据、临时处理和建议方向分开；证据路径只能指向当前项目内部。
3. 调用 `scripts/record_improvement.ps1`。同一岗位、任务阶段和 Pattern-Key 已存在时，脚本返回原记录，不重复创建。
4. 不把日志内容重复写入岗位最近交接；若问题阻塞当前任务，仍按岗位原有交接规则报告阻塞。
5. 不修改总框架、模板、其他项目、安装副本或 `.learnings/`。

调用示例：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<Skill目录>\scripts\record_improvement.ps1" `
  -Role B -Category '契约不清' -TaskPhase '剧本版本整理' `
  -Summary '废稿保留规则没有固定入口' `
  -Observation '同一主文件持续累积多版完整废稿，读取上下文不断增长。' `
  -Impact '后续读取成本增加，当前采用版本更难定位。' `
  -EvidencePath 'B_故事剧本.md' -SuggestedTarget '项目模板或剧本 Skill'
```

## 维护查看模式

用户只说“查看、检查、复盘改进日志”时保持零写入。

1. 读取工作流根目录 `AGENTS.md` 和 `HANDOFF.md`。
2. 调用 `scripts/scan_improvements.ps1`；默认扫描配置中的全部项目，可用 `-ProjectName` 限定。
3. 核对每条记录的项目、证据路径、事实与建议，按 Pattern-Key 合并观察，但保留原 WFI ID。
4. 按 ID 输出：成立、证据不足、重复、项目特例、可能修改位置。
5. 不建立候选区、不改日志状态、不修改活动工作流，并请用户点名要处理的 WFI。

## 维护修改模式

只有用户同时满足以下两项时才能写入：明确点名一个或多个完整 WFI ID；明确说“修改、采用、处理或晋升”。“看看全部问题”“按你判断优化”不足以授权修改未点名记录。

1. 重新扫描并确认点名记录仍位于 `待处理/`，证据路径有效，记录未被并发处理。
2. 记录目标文件 SHA-256，并在 `90_维护资料/升级备份/` 建立本批备份。
3. 在 `90_维护资料/升级候选/` 的独立批次中完成最小修改。不得把正式项目当测试夹具。
4. 根据问题修改总框架、权威模板、源码 Skill、启动器或安装器；不得顺手处理未点名记录。
5. 运行相关确定性测试、Skill 快速校验、隔离安装测试和 `安装工作流.ps1 -VerifyOnly`。失败时只回退本批活动修改，记录保持待定。
6. 验证成功后更新 `HANDOFF.md` 和验收报告，再调用 `scripts/resolve_improvement.ps1` 并传入扫描时记录的 SHA-256：晋升用“采用”，用户拒绝或项目特例用“停用”。
7. 已处理记录移入本项目 `流程改进日志/已处理/`，不删除历史证据。

详细字段、分类和状态见 [日志契约](references/log-contract.md)。

## 固定边界

- 本 Skill 是根级维护能力，不是第六岗位，不分配影视对象 ID。
- `流程改进日志/` 由本 Skill 独占写入；A/B/C/D/E 不直接编辑日志文件。
- `-Role E` 只在项目真实存在 `E_发行复盘.md` 时允许；旧项目没有 E 时明确停止，不创建或迁移岗位文件。
- `.learnings/` 继续保存工具、维护开发和通用代理问题，不与影视流程日志重复。
- 不读取旧项目创作正文来寻找问题；只读取待处理日志及日志明确引用的最小证据。
- 不发送、发布、生成媒体，也不迁移用户未授权的既有项目。
