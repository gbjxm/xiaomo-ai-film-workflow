# 输出与写回契约

## 两阶段门槛

### 第一阶段：策略草案

必须包含：

```text
段落叙事任务：
主要情绪与信息节拍：
观众视点：
人物和空间基准：
视觉强度变化：
需要的镜头覆盖：
预计镜头数量和总时长：
现有与缺失资产：
AI 生成风险：
需要用户确认的唯一关键选择：
```

“人物和空间基准”必须在一个字段内覆盖人物起止位置与调度、关系／行动轴、主要屏幕方向、入口出口和空间锚点，不把这些拆成新的固定日常表格。

两人以上互动、追逐、多人换位或复杂动作场景，可在十项之后条件性追加：

```text
空间／轴线示意：
```

简单单人场景不强制追加示意图。

限制：

- 不分配正式 `V` 编号。
- 不创建镜头方案文件。
- 不更新 C 索引。
- 不输出最终生成提示词。
- 不用多轮参数问卷代替一个真正关键的导演选择。

### 第二阶段：逐镜草案

只有策略被明确确认后才能展开。输出顺序：

1. 策略摘要与本版假设。
2. 镜头组推进与镜头总览。
3. 逐镜方案。
4. 静态分镜描述与排版。
5. 动态预演时间线。
6. 连续性与生成前理论可生成/可衔接检查。
7. 待确认事项及后续交接。

第二阶段初次输出默认状态为“待定”。用户明确说“采用”“按这版写入”“就这样”等后，项目模式才写回；独立模式只把状态更新为“采用”，不创建文件。

## 逐镜字段

每个镜头使用以下最小结构：

```text
镜头 ID：Vxx
场景节拍位置：
镜头任务与主要功能：
建议时长：
可见动作：起点 / 过程 / 终点
开始状态 / 结束状态：
景别：
视点与构图重点：
信息尺度 / 焦点策略：
摄影机：固定 / 运动方式
运动触发点与结束构图：
轴线侧 / 屏幕方向 / 视线关系：
光源动机 / 方向 / 光质 / 反差：
切入动机 / 切出动机：
必要的声音接口：
与镜头组视觉推进的关系：
所需资产：
连续性要求：
AI 生成风险与必要替代方案：
状态：待定 / 采用 / 停用
```

按需字段可接在“景别”或“摄影机”之后：

```text
焦距与主体距离：
焦点策略：
精确机位与角度：
特殊光学：
光线变化：
精确声音接口参数：
```

“必要的声音接口”只写会改变切点、节拍、画外信息或可见反应的声音；没有时可写“无”。没有叙事或制作作用的技术字段不填，不写“默认电影感”。

## V 编号规则

### 语义

`V01` 表示一个稳定的计划镜头，从镜头方案贯穿：

```text
镜头规划 -> Vxx Setup -> 提示词卡 -> Vxx-Bnn-Tnn -> C 生成结果索引 -> D 粗剪与成片
```

它不是某个文件，也不是某次生成结果。

### 分配

- 项目模式先扫描 `C_视觉生成.md` 的两个 V 索引和 `镜头规划/` 中已使用的 V 编号。
- 从历史最大值加一开始分配，不填补空号，不回收停用号。
- 同一批镜头按叙事顺序递增。
- 独立模式从 `V01` 开始即可，并说明只属于当前方案。

### 版本

- 功能不变，技术实现或动作细节修改：保留 ID，镜头方案版本递增，如 `V02 v02`。
- 主要任务或叙事功能改变：旧 ID 标“停用”，新建下一个 V ID。
- 生成结果沿用 V ID，以结果版本或候选后缀区分，不生成新的镜头 ID。

## 项目模式识别

满足下列结构才执行项目写回：

```text
开始这里.md
A_总控.md
B_故事剧本.md
C_视觉生成.md
```

写回前必须确认：

- A 当前任务交给 C。
- 输入段落已有 `Sxx` 编号。
- 用户已经确认第一阶段策略。
- 用户已经明确采用第二阶段逐镜方案。
- v0.8 已读取当前场景制作卡的采用导演基准与站 4 适用性；旧项目没有该契约时不补建。
- 待写文件没有无法解释的冲突。
- 已记录 `C_视觉生成.md` 与潜在镜头方案文件首次读取时的 SHA-256；新文件记录预期不存在。
- 写前 SHA-256 复核未发现并发修改；发生变化时必须停止，不覆盖。

当前段落在 `C_视觉生成.md` 中存在已采用表演方案时，还必须先读取该方案，并把角色目标、关系变化、表演节拍、动作链、关键反应和首尾状态作为镜头约束。镜头规划不得改写这些内容；存在冲突时返回 `$direct-ai-character-performance` 或 C 讨论。

不满足任一项时，只在聊天中交付或路由，不越权修复 A/B/D。

## 项目写回位置

### 镜头方案文件

路径：

```text
镜头规划/Sxx_镜头方案.md
```

使用 `assets/shot-plan-template.md` 的结构。首次写入创建文件；修改同一段落时更新版本和决策记录，不另建无意义副本。

### C 镜头规划索引

每个剧本段落一行：

```text
| 段落 ID | 方案文件 | 状态 | 方案版本 | 镜头范围 | 总时长 | 当前问题 |
```

“当前问题”只填写尚未解决且会阻碍镜头方案执行的问题，例如空间基准冲突、关键表演无法被现有覆盖承载或资产缺口会使镜头整体作废。逐镜表演、提示词、资产定稿、生成等正常后续工作不是镜头问题，必须写入“最近交接”的“仍然待定”和“建议下一步”；没有实际问题时写“无”。

### C 生成结果索引

确认计划后即建立 V 行，即使尚未生成：

```text
| 镜头 ID | 功能/内容 | 持久状态 | 镜头方案版本 | Setup | 当前 take | 关联 S/A | 技术可用性 |
```

未生成时：

- 状态写“采用”或按确认结果写“待定”。
- 镜头方案版本写 `plan v01`。
- Setup 与当前 take 留空。
- 技术可用性写“待生成”。

生成结果出现后由 C 更新结果版本、文件和技术可用性；本 Skill 不评价结果。

### 给 Vxx Setup 的接口

每个采用 `Vxx` 向 `$direct-ai-scene-production` 返回：镜头方案版本/路径/SHA-256、视点与信息尺度、机位/轴线、焦点、构图、运动理由、光源动机/方向/光质/反差、静态预演、动态预演、功能化 coverage、首尾状态、声音/口型/剪辑接口、工具风险与必要替代。不得直接宣布 Setup 就绪。

### C 最近交接

只在本轮任务完成、暂停或切换岗位时更新：

```text
本次完成：
已经写入：
仍然待定：
发现的问题：
建议下一步：
需要 A 判断：
```

如果第二阶段没有被采用，明确写“镜头草案尚未成为项目事实”，不要创建采用索引。

## 禁止写入

本 Skill 不修改：

- `A_总控.md`
- `B_故事剧本.md`
- `D_后期剪辑.md`（未迁移的既有项目可保留旧 D 主文件名）
- 已有媒体文件
- 与当前 A 任务无关的提示词卡和资产

如果发现故事缺口，在输出或 C 最近交接中描述需要 B 解决的问题；不要直接修 B 文件。

## 独立模式

独立模式：

- 不搜索或猜测 v0.7 项目路径。
- 草案阶段零写入；暂停或切换岗位只能写 C 的待定摘要和最近交接。
- 不创建 `镜头规划/`、C 索引或任何本地文件。
- 可使用临时 `V01` 编号完成方案。
- 清楚说明后续可将已采用镜头交给图片或视频模型格式器。

## 信息不足与单问题原则

以下任一缺失会阻止逐镜规划：

- 人物目标或当前意图。
- 可见行动或可见状态变化。
- 基本场景、参与者或空间关系。

如果一个答案即可继续，只问最影响镜头结构的问题。若是剧本层面缺口，路由 B 并列出缺失项，不连续追问摄影参数。

## 边界交接

| 下一项工作 | 交给谁 |
| --- | --- |
| 人物目标、行动、因果、情绪或故事段落需修改 | B_故事剧本 |
| 对白、关系变化、关键反应或动作戏尚无采用表演主线 | `$direct-ai-character-performance` 第一遍，仍在 C 岗位 |
| 已有 V 镜头需要逐镜表演、对白或动作落位 | `$direct-ai-character-performance` 第二遍，仍在 C 岗位 |
| 分镜图或生图的最终可复制提示词 | 完成必要表演落位后交给 `$format-gpt-image-2-prompt`，仍在 C 岗位 |
| Seedance 2 生视频的最终可复制提示词 | 完成必要表演落位后交给 `$format-seedance-2-prompt`，仍在 C 岗位 |
| 生成结果的视觉/技术诊断、资产文件和提示词版本 | C_视觉生成 |
| 粗剪组合、节奏、声音、调色与成片质检 | 经 A 路由 D_后期剪辑 |
| 跨岗位归因不清或需要重新安排任务 | A_总控流程 |

任何一次生成失败都不能由本 Skill 直接触发全故事重写。
