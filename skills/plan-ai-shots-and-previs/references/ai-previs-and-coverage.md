# AI 预演与镜头覆盖

## 目的

预演不是把剧本逐句配图，也不是提前完成成片。它是在生成前验证五件事：段落任务是否可见、调度与空间基准是否成立、镜头是否有可剪接口、每个生成单元是否足够稳定、首尾状态是否能连续。

## 从段落到视觉节拍

先把段落拆成“观众认知或情绪发生变化”的节拍，而不是按句号拆镜头。常见节拍包括：

- 建立人物目标与空间条件。
- 出现阻力、异常或新信息。
- 人物采取行动。
- 行动产生可见结果。
- 人物领会、误解或决定。
- 关系、风险或目标发生变化。

一个节拍可以由一个镜头内部完成，也可以需要动作镜头与反应镜头共同完成。只有当观看位置、时间、空间或主要任务必须改变时才拆镜。

## 调度、空间与轴线基准

先写人物为什么移动、从哪里到哪里、移动后关系怎样变化，再决定摄影机是否跟随、等待、重新构图或保持不动。人物移动与摄影机移动必须分别有动机。

第一阶段的“人物和空间基准”至少包含：

- 人物与关键道具的起止位置。
- 关系轴、主要行动轴或视线轴。
- 主要屏幕方向和入口出口。
- 前中后景的空间锚点。
- 计划摄影机保持在哪一侧，以及何时可能建立新基准。

两人以上互动、追逐、多人换位或复杂动作场景，条件性补充简洁空间／轴线图。简单单人场景若位置和方向没有复杂变化，不画图。

## 覆盖策略

### 最小充分覆盖

覆盖的目标不是给剪辑无限选择，而是保留段落成立所需的最少接口。逐项判断是否需要：

| 覆盖 | 何时需要 | 何时可以省略 |
| --- | --- | --- |
| 空间基准 | 后续动作依赖入口、出口、距离、方向或人物位置 | 空间已经由上一段落清楚建立，且本段不改变 |
| 主关系 | 人物距离、权力或共同目标需要同框被看见 | 单人主观段落且关系不构成当前信息 |
| 动作因果 | 起点、接触点或结果必须清楚 | 动作可在一个稳定镜头内完整读懂 |
| 关键反应 | 反应改变观众对事件的理解或兑现情绪 | 反应没有新增意义，只重复台词 |
| 关键细节 | 道具、读数、伤口或手部动作触发因果 | 细节在主镜头中已足够清楚 |
| 切出或声音桥 | 需要压缩时间、连接空间或保留悬念 | 只是为了遮盖没有设计好的镜头 |

优先保证“刺激物 -> 可见行动或信息 -> 结果 -> 必要反应”的因果链。不要为每句对白都配反打，也不要用漂亮空镜替代剧情信息。

覆盖应服务镜头组的基准、变化、兑现和交接。若同一镜头能通过内部调度完整承担相邻功能，不为覆盖表另造镜头。

### 长镜头与一镜到底

用户选择长镜头时，以内部调度和注意力转移代替机械切镜：

1. 列出镜头内部的连续节拍。
2. 为每个节拍确定人物动作、视觉重点和空间锚点。
3. 写出摄影机运动的触发点与每次阶段性结束构图。
4. 标记无法稳定连续生成的变景、换装、多人交互、复杂手部动作或身份一致性风险。
5. 保留原方案，同时给出最小保底方案，例如隐藏切点、遮挡转场、拆成两个功能连续的镜头或用声音桥连接。

替代方案是风险控制，不是擅自推翻用户的一镜到底意图。

## 可剪辑性

### 每镜的剪辑接口

每个镜头至少建立一种明确接口：

- 动作接口：上一镜动作在下一镜继续或完成。
- 视线接口：人物看向某处，下一镜兑现所见。
- 构图接口：视觉重点或眼迹在切点附近可追踪。
- 方向接口：人物或物体保持屏幕运动方向。
- 声音接口：声音提前进入或延后离开，连接空间与节拍。
- 图形接口：形状、明暗、色彩或运动形成有意匹配或反差。
- 信息接口：上一镜提出问题，下一镜提供答案、延迟或反转。

“硬切”只是转场形式，不是剪辑关系。仍需分别说明切入动机、切出动机，以及观众切过去后首先看见或听见什么。

### 动作覆盖

涉及操作、搏斗、救援、手术、物体转移或复杂道具时，明确：

1. 动作开始前的人物和道具状态。
2. 动作发起者、受力对象和方向。
3. 必须看清的接触点。
4. 动作结果及谁最先反应。
5. 下一镜继承的手位、身体朝向、道具位置和环境变化。

若一个动作的起点、接触点和结果无法在同一生成单元稳定呈现，应按因果节点拆分，而不是随机换景别。

## AI 单镜动作复杂度

### 一个主要动作单元

默认让每个生成镜头承担一个主要动作单元，例如：

- 人物走到门边并停下。
- 人物抬眼看向画外目标。
- 手按下按钮，指示灯亮起。

“走进房间、换装、拿起物品、转身争吵、窗外爆炸、摄影机环绕并拉焦”包含多个独立状态变化，风险极高。即使目标模型理论上支持较长时长，也不应把时长上限当作动作复杂度预算。

### 高风险信号

- 多名角色同时进行不同精细动作。
- 手、工具、液体、伤口或机械接口需要精确接触。
- 镜头内发生大幅换装、年龄变化、身份变化或场景变形。
- 多次遮挡后仍要求角色和道具完全一致。
- 复杂环绕、越轴、镜面、透明材质或反射同时出现。
- 镜头既要大范围移动，又要精确表演和焦点转换。
- 首帧和尾帧状态差异过大，中间缺少可描述的动作路径。

风险处理顺序：简化次要动作 -> 固定摄影机或角色之一 -> 拆分因果节点 -> 利用遮挡或声音桥 -> 更换镜头策略。不要第一步就重写故事。

## 首尾状态

每个 `V` 镜头都要写开始状态和结束状态。至少检查：

| 连续性维度 | 开始/结束应记录什么 |
| --- | --- |
| 人物 | 位置、朝向、姿态、视线方向与目标、手部占用、明显表情状态 |
| 道具 | 所属者、位置、方向、开关/破损/液体等状态 |
| 空间 | 入口出口、前中后景锚点、屏幕方向、关系／行动轴及摄影机所在侧 |
| 摄影机 | 景别、视点、起止构图、运动是否停稳 |
| 环境 | 时段、天气、光源方向、烟尘/水/破坏等变化 |
| 声音 | 正在持续、刚触发或将在下一镜延续的关键声音 |

下一镜的开始状态必须能继承上一镜的结束状态，或明确说明发生了时间跳跃、空间跳跃、视点跳跃或有意不连续。

## 静态预演

静态分镜选择最能证明镜头任务的动作瞬间，而不是选择最漂亮的一帧。每格记录：

- `V` 编号与建议时长。
- 画面范围和观看位置。
- 人物、道具、入口与出口位置。
- 当前动作瞬间。
- 第一和第二视觉重点。
- 与前后镜相接的连续性锚点。

排版规则：

- 1-4 镜：最多 2x2。
- 5-6 镜：最多 3x2。
- 7-9 镜：3x3。
- 超过 9 镜：拆成多张连续编号的分镜表。

格数服从镜头数。空余格保持空白，不为了满足“3x3”字样制造九个镜头。

## 动态预演

动态预演是以秒为单位的镜头接口检查。每行记录：

- 镜头 ID。
- 入点、出点和时长。
- 人物可见动作。
- 摄影机行为。
- 前后镜转场与切点依据。
- 用于节拍或连接的声音提示。
- 开始状态与结束状态。

时间线检查：

1. 入点从零或段落指定时间开始。
2. 当前出点等于下一镜入点，除非明确设计重叠、黑场或间隔。
3. 各镜时长之和等于段落总时长。
4. 对白、动作和反应拥有最低可读时间。
5. 快节奏不等于每镜都短；切点由信息和动作节点决定。

## 视觉推进

先把镜头组写成“基准 -> 变化 -> 兑现 -> 交接”，再选择少数视觉与声音变量推进：

- 景别由远到近，或在关键时刻突然拉开。
- 客观视点逐渐靠近角色，或从主观退回客观。
- 构图由平衡变失衡，再恢复或彻底破坏。
- 空间由开放变封闭，或由平面变纵深。
- 摄影机由固定变运动，或在高潮突然停止。
- 视觉重点由单一变双重冲突，或由混乱收束到一个细节。
- 声音由环境基准转为主观细节、跨镜桥接或突然沉默。

技术变化必须对应认知、关系、行动或情绪变化。不要让每镜都使用不同焦段、角度和运动，导致风格随机跳动。

## 生成风险与替代方案写法

风险要具体到可失败的状态，而不是笼统写“AI 可能不稳定”。推荐格式：

```text
风险：两人同时交换精细道具，手指与道具归属可能漂移。
保留目标：观众必须看清道具从甲转到乙。
最小替代：拆成甲递出、接触点插入、乙接住三个可连接动作；保持道具方向和双方手位。
```

替代方案必须保留原镜头的主要叙事任务。若替代后任务也改变，应回到镜头策略重新确认，而不是静默替换。

## 工具中立

不硬编码任何图像或视频模型的时长、分辨率、镜头控制或参数上限。具体模型能力会变化，应由后续提示词与生成岗位结合当前工具核验。本 Skill 只处理跨模型稳定成立的镜头任务、调度、动作复杂度、连续性、镜头组和剪辑接口；真实素材的实际切点、节奏和声音结果由 D 岗位判断。
