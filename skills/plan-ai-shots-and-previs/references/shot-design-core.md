## 五层镜头工作模型

| 层级 | 核心问题 | 最小产物 |
| --- | --- | --- |
| 场景任务 | 人物、关系、信息或情绪发生什么变化 | 一句话任务、节拍、观众视点 |
| 人物与空间调度 | 人物、道具、入口出口和摄影机怎样让变化可见 | 起止位置、关系／行动轴、屏幕方向、空间锚点 |
| 单镜头设计 | 此刻看什么、从哪里看、先看什么 | 镜头任务、可见动作、构图与摄影机行为 |
| 镜头衔接与覆盖 | 上下镜怎样延续或有意改变动作、空间、注意力和声音 | 最小覆盖、切点动机、开始／结束状态 |
| 镜头组、时间与视听节奏 | 镜头关系怎样形成场景推进 | 基准、变化、兑现、交接及声音时间线 |

制作接口贯穿五层：把方案转成稳定 V 编号、静动态预演、生成单元和可交给 D 的剪辑素材。不要把模型一次输出误当成镜头的定义。

## 核心原则

1. **任务先于技术。** 先写观众必须发现、感到或期待什么，再决定镜头功能和技术手段。
2. **拆开空间参数。** 景别回答“看多少”；焦距回答“视角多宽”；摄影机与主体距离决定透视和前后尺度关系。
3. **拆开机位参数。** 机位高度回答摄影机在哪里；俯仰、滚转和水平方位回答摄影机朝哪里看。
4. **拆开观看与构图。** 视点关系决定观众站在谁的位置；构图决定第一眼、第二眼和画外预期。
5. **运动必须有因果。** 任何摄影机运动都要有起始构图、剧情触发、运动过程、新增信息和结束构图。
6. **形式没有固定情绪。** 景别、焦距、角度、构图和运动只提供倾向；意义由剧情、表演、调度、光线、声音、时长及上下镜头共同建立。
7. **连续性是认知工具。** 轴线、方向和匹配用于维持可读性；可以有意破坏，但必须说明表达收益、认知代价和新基准。
8. **切点必须产生价值。** 能切不等于该切；新镜头应带来信息、关系、动作、情绪、节奏或视点变化。

## 镜头任务

用一句话完成：

```text
这一镜要让观众发现 / 感到 / 期待 ________。
```

有效任务至少完成一项：

- 新增必要信息。
- 改变人物关系或观众立场。
- 推进行动因果。
- 制造、升级或释放压力。
- 建立可用于后续动作的空间。
- 转移观众注意力并兑现一次发现。
- 形成有功能的声音或剪辑连接。

“拍得高级”“增加电影感”“换个角度”不是镜头任务。无法说清独立任务的镜头，应先尝试删除、合并或缩短。

## 十二步镜头与镜头组设计法

### 1. 写场景任务与节拍

明确场景开始与结束时，人物、关系、信息或情绪怎样不同。把变化拆成可见、可听的节拍，不按句号机械拆镜。

### 2. 确定观众视点与信息控制

说明观众靠近谁、知道多少、先看见什么、哪些信息暂时被遮蔽，以及揭示发生在哪个节拍。

### 3. 建立人物和空间基准

记录人物与关键道具的起止位置、入口出口、关系轴或主要行动轴、屏幕方向、前中后景锚点和必要视线关系。两人以上互动、追逐或复杂动作才条件性画空间／轴线简图。

### 4. 设计场面调度

先安排人物如何因目标、阻力、关系或信息变化而移动、停顿、接近、远离、转身和使用道具，再决定摄影机是否需要响应。人物运动和摄影机运动不能混为一件事。

### 5. 选择覆盖策略

用最小充分覆盖保住空间、关系、动作因果、关键反应和必要细节。长镜头以内部节拍和阶段性构图承担覆盖；不为每句对白或每个技术名词增加镜头。

### 6. 写单镜头任务与功能

明确这一镜改变观众的什么认知、情绪或期待，主要功能只选一个，必要时附一个相邻次要功能。判断它是建立、主镜头、关系、单人、动作、反应、插入、切出、揭示、气氛或长镜头。

### 7. 选择景别

- 环境决定人物处境：大远景、远景。
- 身体动作和空间因果：全景、中远景。
- 手势、互动和对白：中景。
- 潜台词、判断和情绪变化：中近景、近景。
- 单一局部触发因果：大特写或插入镜头。

先决定观众必须看见什么，不按“远全中近特”机械排列。

### 8. 选择焦距、距离与焦点

1. 先决定透视、背景尺度和主体与环境的关系。
2. 再选择焦距，并通过摄影机距离取得所需景别。
3. 最后决定深焦、浅焦、跟焦、拉焦或区域对焦。

焦距毫米数是全画幅等效近似范围。所谓广角夸张或长焦压缩，必须连同摄影机距离判断；不能用“广角压迫”“长焦孤独”替代真实空间设计。

### 9. 确定机位、视点与构图

分别决定：

- 机位高度。
- 平视、俯拍、仰拍或正顶等俯仰关系。
- 是否滚转，以及方向和强度。
- 正面、三分之四、侧面或背面等水平方位。
- 客观、主观、半主观、过肩或其他关系视点。

#### 构图检查

依次回答：

1. 第一眼看什么？
2. 第二眼发现什么？
3. 视觉力量与人物行动向哪里移动？
4. 威胁、目标或新信息从哪里进入？
5. 画外空间是否由下一镜或声音兑现？
6. 这一镜相对段落基准在哪项视觉变量上发生亲和、对比、升级或反转？

视觉强度可由空间深度、线条方向、明暗、色彩、运动量、景别距离和节奏改变。高潮不要求所有变量同时增强，但至少一项变化必须可感知。

### 10. 设计人物及摄影机运动

先写人物动作的起点、触发、路径、停顿和终点。固定镜头能完成任务时，不为了“高级感”添加摄影机运动；需要运动时必须写明：

- 起始构图。
- 触发运动的动作或信息节点。
- 路径、方向与大致速度。
- 运动过程中新增的信息。
- 结束构图与下一镜接口。

### 11. 设计剪辑与声音接口

为每镜写明切入动机、切出动机、观众切后先看什么，以及动作、视线、构图、方向、图形、信息或声音中的主要连接。声音可以提前进入、延后离开或用沉默形成段落关节，但实际剪辑仍交给 D。

### 12. 检查连续性、AI 可行性与镜头经济性

- 轴线、视线、屏幕方向与人物左右位置是否可追踪。
- 动作起点、接触点、终点和道具持有位置是否可匹配。
- 光源方向、时段、天气和环境状态是否连续。
- 镜头组是否建立基准、推进变化、兑现节拍并完成交接；景别、焦距与机位变化是否形成节奏，而非随机跳动。
- 最终画幅中的眼睛、字幕、接口、接触点和动作落点是否有安全余量。
- AI 视频单镜是否只承担一个主要动作单元，并有明确首尾状态。
- 删除本镜后若不损失叙事、关系、情绪、节奏或连续性价值，应优先合并或删除。

## 字段使用原则

### 每镜必填

- 镜头所在的场景节拍。
- 镜头任务与主要功能。
- 建议时长。
- 可见动作起点、过程和终点。
- 开始状态与结束状态。
- 景别。
- 视点与构图重点。
- 摄影机固定或运动。
- 运动触发点与结束构图。
- 轴线侧、屏幕方向与视线关系。
- 切入与切出动机。
- 必要的声音接口。
- 与镜头组视觉推进的关系。
- 所需资产。
- 连续性要求。
- AI 风险与必要替代方案。
- 状态。

### 按需填写

只有当它会改变叙事、空间、生成难度或衔接时，才填写：

- 焦距或特殊光学。
- 摄影机与主体的精确距离。
- 焦点策略。
- 精确机位高度、俯仰或滚转强度。
- 光线变化。
- 声音连接。
- 特定画幅安全区。

不确定的技术参数可以留空。错误的精确值比诚实的功能描述更危险。

## 常见概念误区

| 容易混淆 | 正确区分 |
| --- | --- |
| 景别与焦距 | 景别是主体占画面多少；焦距是视角。改变距离可用不同焦距取得相同景别，但透视和背景关系不同。 |
| 机位高度与俯仰角 | 贴地机位可以平视，高位机位也可以平拍；高度与光轴方向必须分开。 |
| 人物运动与摄影机运动 | 人物移动改变关系、景别和构图；摄影机移动改变观看位置。二者可配合，也可只使用其一。 |
| 推进与变焦 | 推进改变摄影机位置和透视；变焦只改变焦距和取景角。 |
| 鸟瞰与正顶拍 | 鸟瞰强调高空宏观范围；正顶拍强调光轴近乎垂直及平面位置关系。 |
| 主观与过肩 | 主观镜头近似替代角色眼睛；过肩仍看得见观察者身体，属于关系视点。 |
| 插入与切出 | 插入是主动作内部的局部；切出暂时离开主动作，展示另一相关信息。 |
| 手持与乱抖 | 手持是受控的人体运动；乱抖会破坏动作、焦点和空间可读性。 |
| 荷兰角与对角线 | 荷兰角来自摄影机滚转；对角线可由水平摄影机画面中的建筑、人物或动作形成。 |
| 深焦与广角 | 广角可能有利于较深景深，深焦仍取决于光圈、距离、对焦、传感器、照度和观看条件。 |
| 构图比例与好构图 | 网格和比例只是组织工具；有效构图必须建立层级、方向、关系和画外空间。 |
| 180 度原则与禁止越轴 | 180 度帮助观众维持关系和方向；可以越轴，但需要表达目的、新基准或重建办法。 |
| 30 度原则与精确角度 | 30 度是避免相邻镜头过于相似的经验规则；真正标准是新镜头是否足够不同且有价值。 |
| 覆盖与镜头越多越安全 | 无差别覆盖增加成本、连续性债务和机械感；安全来自任务明确且接口充分。 |
| 节奏与剪得快 | 节奏来自动作、表演、声音、时长、重复、变化和停顿，不等于高切换频率。 |

## 最低合格线

一个镜头计划不是摄影术语清单。它至少应让下一岗位回答：

- 为什么需要这一镜？
- 镜头开始与结束时，人物、道具和摄影机各是什么状态？
- 它位于哪个场景节拍，与上一镜和下一镜为什么在此处连接？
- 需要哪些已存在或待补的资产？
- 若当前方案超出稳定生成能力，最小替代是什么？

任一问题无法回答时，先补设计，不进入最终提示词。
