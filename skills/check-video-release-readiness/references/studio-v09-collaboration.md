# V0.9 发行前置检查

先完成主文版本路由。前期检查只辨认当前作品候选会带来的发行约束与证据缺口；不要求为咨询先产生 Master、PUB 或切换 A 当前目标。

- 只检查本次明确的传播承诺、素材来源、拟用平台和首映/投稿意图，指出具体事实矛盾或需要收集的证据及责任人；没有相关风险不堆叠通用检查表。
- 平台规则、版权隐私及资格仍依 `release-safety-contract.md` 核验当前适用依据；资料不足标为未确认，不把公开可见等同可使用，也不把方案采用视为权利许可。
- 交付标为“发行前置意见”，逐项说明候选依据、实际缺项及何时复核。没有最终精确包时不输出“发布就绪/通过”，不计算与本次纯咨询无关的媒体哈希，不在本 Skill 内修稿、改图或组包。
- 用户要求正式就绪结论时，必须回到主文的精确 CUT/Lock/Master/组件、最终包、封面、当前平台、版权与首映门，并核验真实输入。实际能力关闭时只报告尚缺的提交或证据；开启时经 Resolve 读取已采用快照，检查文本由所属 E 通过 Adopt 保存，不调用旧写回流程；所有真实媒体与发布动作仍由共同契约限制。
