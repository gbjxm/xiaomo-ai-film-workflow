# 画面、VFX、色彩、文字与图文

## 所有权与返回门

C 拥有生成前的生产设计、角色/资产状态、表演、调度、摄影灯光意图、画内文字与源媒体内容。D 拥有色彩管理、镜头匹配、最终调色/Look、既有元素合成、Online、画外字幕/GFX 和画面 QC。

纯后期匹配、清理、稳定、现有元素合成、色彩管理、Online 与画外图文留在 D。若修整会改变角色身份、场景事实、镜头功能，或需要新源画面，停止并经 A 返回 C；D 不生成替代素材、不修改 C 原件。

## PIC

按风险处理以下子项，而非强制全部展开：

- VFX/修复：只对现有媒体执行获授权的合成、清理、稳定或修复，记录源与派生 hash；
- Online/conform：重连高质量采用媒体，核对变速、缩放、重定位、转场、帧准确性和渲染；
- 色彩管理：确认源色彩身份、工作与输出空间、监看基线、LUT/变换和例外；
- 镜头匹配与最终 Look：保持叙事连续性，同时允许有意的视觉弧线；
- 画面 QC：黑帧、闪帧、冻结、生成瑕疵、边缘、构图安全、画幅和输出一致性。

PIC 使用五状态。没有 VFX 不等于 PIC 不适用：Online、色彩和画面 QC 仍可触发；各子分支可分别记录不适用原因。冻结 PIC 必须绑定精确 CUT/Lock、版本、路径和 SHA-256。

## 达芬奇调色专业调用

调色使用 [grade-film-in-resolve](../../grade-film-in-resolve/SKILL.md) 的专业方法，原生接口由 [davinci-resolve-mcp](../../davinci-resolve-mcp/SKILL.md) 按实测能力执行。专业上区分输入解释、技术平衡、场景匹配、共享 Look、必要局部与按需质感，并做动态复看和原生输出回读；共享 Look 不等于所有镜头复制同一参数包，判断层也不是固定节点顺序。

默认在同一指定工程中持续调整一版，明确测试才原版与三个候选。DRX 等节点覆盖须有真实恢复点；LUT 不代表窗口、跟踪或纹理效果。所有实际操作仍须本次执行授权，不使用键鼠或默认外部 FFmpeg 调色。工作稿和测试导出保留候选身份，正式采用后才由 D 更新相应 PIC/调色指针；不创造 CUT，不宣称最终 Master QC 已通过。

## TEXT 与 GFX 分离

TEXT 管理可读文字轨：普通字幕、翻译字幕、SDH、Forced Narrative 及其文本、时码、断句、阅读速度、样式和校对。GFX 管理画外标题、片头片尾、署名、卡片、标识与其他图文。

按真实需要记录：

- TEXT：语言、类型、源文本、时间码、样式、安全区、烧录/外挂、文件路径/hash、校对和版本；
- GFX：内容、来源资产、位置、时长、运动、字体/许可、安全区、透明通道、文件路径/hash 和版本。

无字幕、无翻译、无 SDH、无 Forced Narrative 或无 GFX 均可分别标 `不适用＋原因`。不要因为某一文字分支不适用而省略实际触发的其他分支。

## 冻结与失效

- CUT 顺序、切点、时长或采用媒体变化时，逐项检查 PIC/TEXT/GFX 的时码与画面依赖；只失效受影响项。
- 只改 TEXT 或 GFX 不提升 CUT，不无差别使 PIC/AUD 失效；使变化组件、Master 和对应 QC 失效。
- 只改最终调色或 PIC 内容不必新建 CUT，但 PIC、Master 与 QC 升版/失效；若画面时序或采用媒体也改变，则按 CUT 规则处理。
- Master 汇合前，TEXT 与 GFX 必须各有精确冻结版本或合法不适用原因，不能用“字幕完成”笼统替代两项状态。
