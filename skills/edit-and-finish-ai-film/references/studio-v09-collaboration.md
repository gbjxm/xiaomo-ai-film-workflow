# V0.9 前期剪辑与声音协作

先完成主文版本路由。本页把前期专业咨询与真实后期证明分开；保存与采用先读实际能力，通过共同运行接口办理，不落入旧写回步骤。`media_execution` 仍指工作室运行时内置媒体功能并保持关闭；独立达芬奇原生工具的使用另以实际接口可用和本次用户执行授权为前提，不修改该字段。

## 前期咨询

- B/C1/C2 可直接请求 D 的受限专业意见，无需 A 切换唯一目标、领取 D 旧租约、取得 C 交接清单或建立素材接管。输入只需点名的故事/片段候选、预计时长、相邻接口和实际工具限制；没有真实媒体也能做方案判断。
- 剪辑意见指出观众理解事件所需的信息、动作阶段、关键反应和空间交代；说明哪些镜头功能不可替代、哪里能接、哪里需要停留，以及缺口会怎样破坏理解。需要时读取 `edit-cut-and-picture-lock.md` 的专业方法，不执行其中正式 CUT/Lock 步骤。
- 声音意见应说明对白、画外声、环境、效果、音乐或沉默承担的叙事任务、发生时点及与可见反应/口型的关系；明确哪些声音需在生成时保留，哪些可由用户后期补做。需要时读取 `sound-and-music.md`，不默认展开完整混音工程。
- 出现特殊时基、画幅、VFX、字幕/口型或生成前 Look 风险时，按需读取 `post-preset-and-ingest.md` 或 `picture-vfx-color-text-gfx.md`，给出会影响本次拍法或输入的具体限制；不先接管媒体、不把前期预期称为已完成调色。
- 返回点名镜头/节拍、具体问题、最小修正及对 C1/C2 的接口，供 C2 整合。不得代改故事、C 源素材或候选提示词；需要剧情改变时给 B 候选问题。

## 用户带回组接或素材

用户提供真实组接后，可只读审看片段并诊断；没有正式接管不妨碍受限诊断，但不得据此创建 CUT、宣布锁画或形成正式 QC。依赖画面/声音的判断必须实际看/听对应媒体；只有描述时明确是方案推断。

## 正式后期

正式接管、CUT、Lock、四组件、Master、QC 与恢复仍必须满足主文及专业 references 的真实输入和证据要求，不能用前期咨询回执替代。工作集与事务能力开启时可 SaveDraft 保存方案，由 D 准备明确采用的完整文本经 Adopt 提交；上游采用内容先 Resolve。相应工作集或采用事务能力关闭时，对应文本动作只列具体缺项或保留演练决定，不据此否定独立达芬奇工具的实际可用性与动作授权。ResumeSync 只恢复文本提交和视图，不能冒充工程重开、媒体恢复或 QC；media_execution 仍为 false。

D 默认使用达芬奇后台原生 API/MCP，不占键鼠。按需由 `grade-film-in-resolve` 承担调色专业判断、`davinci-resolve-mcp` 承担技术接口；工具不决定创作，D 主入口和正式记录所有权不变。实际接口可用且用户已授权本次执行时，在指定工程内操作；否则完成方案或接回用户手工结果，不因安装扩张权限。

正式工作默认只有用户指定的一版，并在同一工程中继续调整；明确要求测试时才保留原版与三个候选，范围与方向按用户要求和影片决定。先核对输入、影片意图与基础匹配，再按需处理 Look、局部和质感，完整动态复看、原生导出回读；不固定参数或每镜堆满效果。候选与真实导出不自动写成采用，正式采用后由 D 更新对应记录和实际依赖。没有执行事实不报告已剪辑、混音、导出或通过 QC，不把局部接口测试写成全部 API 或影片效果通过。

## 按片段与源区间取用素材

需要定位同片段多条完整原片或已有可用区间时，调用 `organize-ai-film-media` 的查询/登记能力；默认只读点名原片及相关索引，不扫描完整素材树。区间使用原文件时间，不以剪辑时间线位置覆盖；画面、声音、内部换镜和动作首尾限制分别按实际证据判断。一条文件可多个区间，多条文件可共同组成片段。

复用索引中的来源和候选意见，真实入片选择仍写 D 的精确素材使用表；不能把工具区间记录当作正式采用、可直接拼接或已剪辑。用户已导入工程的文件保持原路径；未核实软件能力前不承诺自动导入区间、生成标记或修改剪映工程。先保留完整原片供切点和余量调整，不预先批量导出小片段。
