# 制作资料路径约定

仅入口显式声明唯一 `workflowDocsLayout: production-docs-v1` 的 studio-v0.9 项目启用。无标识项目继续使用原路径；未知或重复标识停止该次操作。不得凭安装版本、目录名或文件存在推定布局。

结构定义唯一数据源为同目录 `studio-project-layout-v1.json`。其中 documentDirectories 列出的 13 个业务目录统一放在 `90_制作资料/` 下，保留原子目录和文件名。专业 reference 和模板中的旧根相对业务路径在此布局下先加该前缀，再进行专业读写；不包含这些目录的路径保持原义。

| 用途 | 该布局的真实路径示例 |
| --- | --- |
| 剧本工件及完成包 | `90_制作资料/剧本/工作稿/`、`90_制作资料/剧本/阶段完成包/` |
| C1 资产与色彩资料 | `90_制作资料/资产设计/`、`90_制作资料/色卡/` |
| C2 导演、镜头和表演资料 | `90_制作资料/场景制作/`、`90_制作资料/镜头规划/`、`90_制作资料/表演设计/` |
| 提示词与生成记录 | `90_制作资料/提示词卡/`、`90_制作资料/生成记录/`，资产/镜头子分支仍保留 |
| 后期与发行记录 | `90_制作资料/后期方案/`、`90_制作资料/发布包/` |
| 完整候选与短缓存 | `90_制作资料/工作稿/<部门>/<key>/`、`90_制作资料/续接缓存/<key>.json` |
| 流程改进日志 | `90_制作资料/流程改进日志/待处理/`、`90_制作资料/流程改进日志/已处理/` |

`开始这里.md`、A/B/C/D/E 主文件、`工作室能力.json`、`.工作室/` 状态与采用事务均保留在根目录。四个媒体入口保持独立；资产规格不是图片文件，生成记录不是视频本体，发布包记录不是成片文件。本布局不新增或改变专业所有权、影视编号、采用、锁画、QC 或媒体执行能力。

运行时返回真实路径；各专业写入请求、普通 Markdown 链接、依赖和 Adopt/Resolve 选择器都必须使用真实项目相对路径。运行时不把旧目录名当透明别名，也不把现有采用索引、旧快照或源媒体路径自动重写。新布局的旧根业务路径不能用于新的正式提交。

只对新模板或用户点名授权的项目启用。已有真实项目需要独立迁移安排，先保留原件与依赖，再同步指针并验证恢复，不能只移动文件夹或先加标识。本批试用项目没有工作集/采用事实，按已核对的目录内容调整；不外推为有制作数据的项目迁移已验证。
