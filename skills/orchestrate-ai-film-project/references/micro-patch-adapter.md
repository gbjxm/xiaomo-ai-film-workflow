# 同一前台轻量岗位适配器

本适配器只机械执行已经明确采用、已经授权记录写入、无需新增专业判断的精确差量。它把文件所有权绑定到受限岗位能力，而不是绑定到用户当前聊天标题；当前前台不得绕过本契约直接改其他岗位文件。

仅当项目入口声明 `workflowPatch: single-foreground-micropatch-v1`，并且 [任务与里程碑契约](task-and-milestone-contract.md#后台所有权微补丁) 的全部门成立时启用。

## 执行优先级

1. **同一前台受限适配器，默认**：在当前一次回复内依次激活文件所有者适配器、A 指针适配器和前台重绑；不创建新任务、不重新加载完整岗位提示词。
2. **既有所有者任务或受限子任务，降级**：差量需要所属岗位的新专业判断、当前运行时不能保证写入白名单，或独立上下文能显著降低错误风险时使用；用户仍不切任务、不复制。
3. **A 决策**：任一微补丁门不成立时停止适配器。重大串行路由使用正式暂离/恢复，不伪装成微补丁。

同一运行时可以顺序写三个岗位文件，但每一步必须显式声明执行身份、写入白名单、写前 hash、实际差量和回执。它算三段受限岗位动作，不算前台岗位直接越权写入。

## 最小读取

- 项目入口只读能力标识和共享确认门，不重复读取五段完整启动词。
- A 只读当前任务、当前有效指针和目标文件 hash。
- 所有者只读点名对象、必要索引/修改记录、目标文件 hash 和不变量。
- 前台只读自己的旧绑定及所有者/A 新回执。
- 默认不读完整岗位主文件的无关区块，不读常规专业 references，不读其他岗位正文。精确差量需要重新创作、诊断或专业取舍时停止轻量适配器，降级到所有者任务。

## 固定事务

1. 前台计算 A、所有者、前台三个写前 SHA-256，核对来源任务 ID、A 任务版本/hash、采用证据和记录写入授权证据。
2. 激活所有者适配器，只允许写所有者白名单内的精确文件；保持稳定 ID/制作功能，提升必要版本，验证不变量，返回新 hash、实际差量和影响。
3. 重读 A 与所有者回执，激活 A 指针适配器；只允许写 `A_总控.md` 的对象版本/hash、受影响执行坐标和同步状态，不审批内容、不改变权威执行目标。
4. 重读 A/所有者，恢复前台身份；只允许写前台自己的引用、失效/待复核和恢复状态。
5. 输出一次结果。任一步 hash 不符或回执不完整即停止；已经成功的历史写入不自动回滚，按共同契约恢复。

## 岗位白名单

| 适配器身份 | 可机械处理 | 写入白名单 | 必须降级 |
| --- | --- | --- | --- |
| B | 同一 `Sxx`、同一制作功能内的精确措辞/动作替换、版本、索引、修改记录、交接 | `B_故事剧本.md` | 新故事判断、功能/事件/动机/结果改变、新 `Sxx` |
| C | 同一稳定 C 对象/制作功能内的精确引用、状态、版本或记录修正；不执行生成 | C 主文件及该对象原属 C 记录 | 需要新资产/表演/镜头判断、媒体生成、锁定下游 |
| D | 同一 D 阶段内精确记录、组件版本和失效传播；不修改媒体或时间线 | D 主文件及 D 原属记录 | 真实剪辑/声音/转码/导出、改 Profile/结构、已锁定下游跨岗 |
| E | 同一 PUB/Master/平台/承诺内的精确文字、字段、版本和失效传播；不制作媒体 | E 主文件及 E 原属记录 | 新 PUB 条件、Master 修改、封面媒体执行、权利/发布动作 |
| A 指针 | 对象版本/hash、受影响执行坐标、同步/恢复状态 | `A_总控.md` | 内容审批、专业正文、里程碑或权利判断 |

## Token 与体验证据

- 默认新建任务数 `0`；用户任务切换 `0`；用户复制 `0`；用户只给一次精确决定/授权。
- 只传固定差量包和回执，不复制完整文件、完整聊天或完整岗位提示词。
- 若本机能提供线程 `tokens_used`，记录试演前后增量；否则写“精确 token 不可取得”，不得以字节数冒充 token。
- 独立所有者任务是质量降级路径，不得作为普通微补丁默认，否则会重新放大 token 和等待时间。
