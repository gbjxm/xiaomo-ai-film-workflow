# 工作室结构的专业依据与适配范围

核对日期：2026-09-09。下列公开原始资料用于解释职责与协作机制，不是“照此配置即可达到专业成片质量”的证明。日常片段优先使用已维护的专业 Skill 与知识树证据，不每次重复联网读这些组织说明。

| 来源事实 | 本工作室的适配决定 | 范围与限制 |
| --- | --- | --- |
| AFI 将 production design 描述为与导演、摄影协作的整体视觉概念、环境、色彩与视觉叙事 | C2 在资产定稿前与 C1 一起确定视觉及场景用途 | 六部门是个人工作室压缩映射，不是 AFI 规定的部门数 |
| Disney 的 Layout 使用角色、场景、道具和摄影机推进调度、动作、镜头及剪接的迭代 | 复杂片段先联合检查空间、动作和镜头；基础资产与镜头参考分开 | AI 图像/视频并不等于可完全控制的 3D 场景，未显示空间仍须试验 |
| Disney 的 Editorial & Sound 贯穿开发、资产和镜头制作 | D 在前期以轻量咨询检查节奏、对白/声音和必要覆盖，正式组接另按真实媒体 | 不把动画公司安排泛化为所有真人低预算项目的固定雇用顺序 |
| DGA 动作协作讨论强调及早与美术合作，通过预演理解动作和机位，清楚不可妥协项 | 打戏、追逐、受力或复杂互动触发表演/空间/摄影联合推演 | 本工作室设计 AI 画面，不提供真人危险动作执行方案 |
| Disney Lighting 将色彩、反差和光照用于观众注意力、情绪和故事变化 | C2 汇合生成前 Look，C1提供材质本色，D负责最终匹配 | 不能用滤镜名替代场景意图，也不能把前期意图当作实测色彩管理结果 |
| Higgsfield 官方介绍 Hell Grind 的场景提示词、资产和生成记录公开 | 可在实作验证时研究输入与实际结果如何对应 | 尚不把公开项目、工具 Skills 或厂商宣传视为通用工业质量标准 |
