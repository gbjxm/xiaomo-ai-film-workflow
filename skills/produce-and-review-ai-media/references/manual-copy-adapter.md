# manual-copy 适配器

`manual-copy` 是工具不可用或用户尚未授权自动执行时的默认适配器。它是人工交接，不是生成器。

## 必备内容

1. 目标工具：未知时写“由用户选择”，不要猜。
2. 输入文件：逐项给出绝对路径或明确缺失。
3. 可复制的最终提示词：保持采用卡内容，不暗中改故事或镜头。
4. 设置项：只写已知且稳定的设置；不硬编码某家工具易过期参数。
5. 批次建议：说明数量和变量策略，不承诺结果。
6. 输出命名：图片沿用关联 `Axx`；视频使用 `Vxx-Bnn-Tnn`，batch/take 是执行坐标，不是新稳定 ID。
7. 回传要求：原文件、真实路径、SHA-256、工具名、实际参数、时长、帧率、音轨、失败信息和用户主观反馈。
8. 验收标准：可见、可比、能决定采用/停用或返修。

状态始终写“等待人工执行”，直到收到真实文件或工具日志。

交付前必须列出当前 `Vxx Setup vNN` 及其 Profile、工具限制和输入文件路径/hash。Setup 未冻结、提示词虽采用但未获生成授权，均只保持等待，不提交工具。
