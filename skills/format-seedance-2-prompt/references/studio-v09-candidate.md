# V0.9 整合候选的视频格式化

本分支只改变输入来源与候选交付衔接。项目标识和能力结果可复用 C2 本轮已核实结果；必要时只读入口/能力用于版本路由，不读取项目创作文件、历史或附件画面/声音补写事实。

## C2 明确提交一版整案

C2 须明确调用 `$format-seedance-2-prompt`，交付稿件版本、任务模式、整段完整内容、镜头/时间关系、必要素材职责与当前标记约定。已整合候选即可格式化，无需用户先采用表演、策略、逐镜或正式 V。候选仍是候选；无标识或独立调用继续旧确认要求，explicit-only policy 不变。

需要专业新增内容、两版事实冲突、时间关系不明确或缺失上版全文时，返回 C2 关键缺口，让其在当前整案中处理；不让格式器代导演设计，也不重新启动逐专业用户确认。

## 保留的格式与不变量

复用主文件的忠实转换、任务模式、段内画面前置、局部修改、字符上限、外部自包含及分区诊断规则；明确内容以 C2 提交的本版为准，旧项目的采用、Setup 和正式记录门不进入本候选分支。目标仍为 Seedance 2.5，平台限制依实时核验，不从示例推出参数。

素材标记以当前 C2 提交包的明确约定为准：既有 `{{Mixed n}}` 或 `@图片n/@视频n/@音频n` 保持原映射，不因续接或局部修改自动互换。包内尚无可用映射时返 C2，不虚构上传成功、真实编号或已核听音频。每个参考保留职责、允许/禁止继承和优先级；场景、身份、状态、构图、运动和声音不得互相冒充。

时间码按原有数值忠实编排，但进入复制层前须确认顺序递增、区间不重叠、镜头延续/切换关系明确。输入总括时段与子时段重叠时，返 C2 解决层级，不擅自删时段或重排剧情。无精确时码时保留已给出的次序，不自行计时。

对于上游已明确同一镜头的连续节拍，使用“延续同一镜头，不切镜”；实际换镜写“切镜至……”。共有镜头信息放首个时间段，后段只保留变化；不能据此把两个独立镜头合并。画面要素前置只改变说明顺序，不提前运镜触发、结束构图、动作结果或同步声音。

保持原有镜头数量、事件因果、动作首尾和时长。疑似过载在框外报告执行风险，不能擅自删动作、拆镜、慢放或补画外音。新创意由 C2 形成下一版输入。

## 候选交付

框外标明“候选提示词｜本稿版本”，框内仍按所需素材职责、基础设定、动作与镜头、画面与声音、注意事项组织，候选声明与内部追溯信息不进入代码块。原有核心诊断和空间光感/空气状态槽位保留；“已足够”不等于正式采用、已生成或可剪。

局部修改必须收到上版完整复制层，只修改点名差量和直接冲突的位置，完整返回。把精确复制层及框外诊断返 C2；格式器不自行创建正式卡。C2 按实际能力 SaveDraft/Adopt 保存，已采用复制层先 Resolve；不启动媒体执行或旧单 C 续接脚本。
