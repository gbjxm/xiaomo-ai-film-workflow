## 按输入方式调整内容

| 方式 | 需要解决的实际问题 |
| --- | --- |
| 文生视频 | 没有图片代为规定身份和空间；上游按本片需要给出可辨固定项、起态、动作、观察和显示意图，而非只列剧情 |
| 图生视频 | 上游先实际核对图能证明什么；文字重点写变化和必要不变量，避免无关重述改掉已有画面。首帧只锚定起点，不能证明中间动作路径 |
| 首尾帧 | 两端须属于同一对象和连续状态；说明中间如何到达，不靠两端各自漂亮推定过渡成立。实际入口未支持则不伪造角色或上传字段 |
| 多模态参考 | 逐项说明身份、空间、构图、动作、运镜、音色等实际职责及排除范围；主体参考不自动继承背景，动作参考不自动继承摄影或声音 |
| 编辑/延长 | 点明保留和变化的范围，承接真实源片的已核状态；未知末帧/原声不能猜。时长和比例的行为由具体入口核验，不沿用文生参数语义 |

## 正向控制与局部排除

先说明想稳定出现的条件，再检查禁止项是否保护这些条件。例如“手离开后筷子仍贴在桌面原位”明确了结果；仅写“不要穿模、不要漂移”还没有定义结果。已有排除项不随意删除；其正向目标不明时返上游，不能把“不要油亮”擅改成哑光或把“不要模糊”改成全景深。

身份、观察位置、接触点、焦点、材料响应与声音各自需要多具体，取决于当前观看目标。情绪和风格词可限定方向，但不替代行为与声画条件；焦距/光圈等数字也不能替代空间判断或证明精确模拟。多镜固定项避免互相改写，每镜说明有意义的差量；兼容复合运镜不按动词个数判错。

## 参数与提示正文分开

上游核验实际平台/型号/模式，格式器沿用明确的输入与素材标记。已知设置在框外区分建议、支持与实际选择；没有操作回执就不声称已设置或生成。正文中的画幅、时长、分辨率和声音要求须与预定设置相容；电影机或“8K”风格词不替代实际输出规格。“不配乐”不等于关闭包含环境音和同步声的音频生成。

2026-09-16 Higgsfield `models_get(seedance_2_5)` 列出文生、全模态参考、编辑、延长模式；可设置比例、时长、分辨率和音频开关，但没有列出独立 `negative_prompt`。这一条是当日该入口的记录，不是所有平台的永久上限或参数契约。需要提交时读取当前目录/官方接口，只传已支持的参数；自然语言排除约束与API字段分别判断。

实际平台未指定时，给出本次已核入口的支持条件和建议，标明目标平台待核；不因此替用户选工具，不把目录存在当套餐可用或提交成功。格式器不新增上传、生成、剪辑或发布动作。

## 用结果校正，而非按栏目认证

交付前，C2对照整合输入与复制层，核对关键时刻的动作/观察/光声及正负向关系，分清上游缺项与转换遗漏。解决本稿关键缺口才说明相应文字设计充分；简单或刻意模糊的用途不机械补全所有摄影细节。未生成时只评价文本；真实结果须按具体媒体观察与核听，不能从指南、字符数、时码或模型目录得出质量、物理稳定性或可剪结论。
