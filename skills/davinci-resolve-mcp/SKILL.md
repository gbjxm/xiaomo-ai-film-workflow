# 达芬奇后台接口

把已确定的操作目标交给官方 Scripting API，并准确报告实际结果。本 Skill 是接口层；剪辑和影片整体判断仍由 D 的 `edit-and-finish-ai-film` 负责，专业调色由 `grade-film-in-resolve` 负责。已有明确执行授权直接沿用；接口可用不增加新的创作或媒体动作授权。

## 连接与对象定位

使用当前已配置的 **Xiaomo Resolve Background** stdio MCP，策略 `xiaomo.resolve-background/v1.3`。先发现当前工具及 `inputSchema`，不要照搬上游全工具清单或示例参数。本机已通过真实 stdio 读取 Studio 20.3.0.10；具体范围见[已验证能力](references/verified-capabilities.md)。

- Resolve 须已运行并开放 Local 外部脚本。无连接时报告当前缺口，不自动启动、重启、关闭软件，不自动安装或注册其他 MCP。
- 当前工程、时间线或素材 ID 必须来自本次连接的真实读取。读取当前工程和当前时间线，再按轨道获取片段；区分媒体池 `clip_id`、时间线 `item_id`、节点 `graph_id`。
- 一些 `project_*` 方法操作当前工程，实际签名不接受 `project_id`。父对象存在不代表要把父 ID 传给每个工具。按实时 schema 调用。
- 工程切换、连接重建后旧注册表对象可能失效，重新读取受影响对象；不要根据名称猜 ID，也不要默默改到当前另一工程。
- 执行中只让一个入口拥有该工程的写入任务。其他任务可以只读，但不得与用户或第二个写入进程同时修改同一对象。

涉及具体编辑、颜色、保存或渲染时，读取[原生接口约束](references/native-operations.md)，按任务使用其中相应部分。

## 硬限制与失败处理

服务器实际移除了未批准工具，当前开放 145 项。完整名单以该安装入口同目录的 `tool-policy.json` 和当前 `list_tools` 为准；名单不是全部能力都已验证的声明。

- 不使用 Computer Use、系统窗口激活、模拟按键、任意 Python/Lua 执行、Fusion 表达式或设置载入。按明确调色任务可调用原生 `resolve_open_page(page_name="color")`，仅进入软件内部 Color 页且不接管系统焦点；其他未开放页面仍不可用。
- 不通过上游裸启动器、直接 shell/SDK、第二套 MCP 或关闭策略来绕过拒绝。确需新接口时，先说明能力缺口并交由独立维护修改与验证。
- 不调用项目删除、应用退出、云工程、Quick Export 上传或未批准的源素材重连/替换。此限制不阻止已授权的片段级编辑；仍须保留可恢复基线。
- 工具超时、返回 False/None、对象过期或出现原生对话框时停止该操作，保留已完成范围；不得默认重复写入、强杀软件或点击弹窗。
- 本策略限制本 MCP 暴露的动作，不能保证 Resolve 的所有原生调用条件下都不出现软件内部对话框。

## 完成口径

分别核对 MCP 的 `isError`、工具返回 JSON 的 `success`、实际工程状态以及需要的渲染/画面证据。API 返回成功不等于素材正确、参数已保存或画面已通过。

本接口不预设静音阈值、剪辑节奏、调色参数、风格、测试时长或变体数。正式一版、测试三版等安排由本次任务传入，不能因工具支持复制就自动制造版本。

交付说明精确工程/时间线、实际操作、可恢复版本、核验结果和未验证项。媒体渲染不等于发布；本 Skill 不处理上传或公开发布。
