# V0.9 发行包装候选咨询

先完成主文版本路由。E 可依据故事/视听候选参与前期讨论，无需先切换 A 当前目标或具备精确 Master；这只开放咨询。

- 针对点名平台和当前作品目标，提出观看承诺、标题/正文候选及兑现它们需要出现的具体内容。平台未知但不影响本轮判断时先给不依赖平台的候选，不虚构平台限制。
- 只把确有材料支持的内容写成事实；尚在创作中的人物、冲突、结果和画面注明候选来源。涉及奖项、平台规则、版权或首映资格时按原专业证据要求核验，未知保留为未确认。
- 返回候选文字、内容依据和待成片核实项，不创建 PUBxx，不生成最终发布包、真实回执或可上传文件，也不接管封面制作与就绪检查。
- 用户要求正式包装时仍需主文规定的精确 CUT/Lock/Master/组件绑定、实际审看及权利证据。按实际能力 SaveDraft 保存候选，采用文本由 E 经 Adopt 提交；关闭能力时仅保留决定。正式消费先 Resolve，不调用旧 E 写回步骤；候选通过不能解除正式门。
