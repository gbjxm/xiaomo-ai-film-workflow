# 发布证据契约

## 对象与唯一事实源

| 对象 | 唯一事实源 |
| --- | --- |
| D Master 基线 | D 交接/绑定记录，保存采用 CUT、Picture Lock、Master 路径/hash/Profile、组件、QC、恢复与权利证据 |
| 包装决定 | `PUBxx_包装决定_vNN.md`，保存传播承诺、采用文案与精确 Master 指针 |
| 最终封面 | 封面记录与真实封面文件 |
| 最终发布包 | `PUBxx_最终发布包_vNN.md`，保存唯一 manual-copy 与所有输入哈希 |
| 发行检查 | `PUBxx_发行检查_vNN.md`，绑定精确最终发布包、Master/组件与封面哈希 |
| 实际发布 | `PUBxx_发布回执_vNN.md`，保存平台实际字段及与计划差异 |
| 发行复盘 | `PUBxx_复盘_vNN.md`，只分析回执中的实际发布版本 |

## 发行阶段证据

| 发行阶段 | 最小证据 |
| --- | --- |
| 可进入 v0.8 包装 | 采用 `CUTxx vNN`、Picture Lock、QC 通过的 `Master vNN` 路径/hash/Profile、PIC/AUD/TEXT/GFX 版本与合法状态、精确绑定表 |
| 包装已采用 | PUB、包装决定、用户采用确认、关联 CUT 与 Master、平台和传播承诺 |
| 封面已采用 | 封面记录、真实可打开文件、来源、版本和 SHA-256 |
| 最终包已采用 | 唯一最终发布包、Master/组件在内的全部输入路径/版本/SHA-256 和 manual-copy |
| 已就绪待人工发布 | 独立发行检查绑定上述精确哈希且结论通过 |
| 已发布 | 实际发布回执、平台、账号代称、真实链接或明确回执和发布时间 |
| 发布失败 | 用户提供的平台错误、失败步骤和未完成动作；不得推断成功 |

## 失效规则

- 候选不占用 PUB；采用包装决定才分配。
- 一个 PUB 只对应一个采用 CUT 精确版本、一个 Master 基线、一个平台和一个主要传播承诺。
- 最终发布包采用后不原地改写。任何输入、文字、平台字段或文件哈希变化都创建新版本。
- Master 的路径、版本、SHA-256、Output Profile 或任一绑定组件变化，旧最终发布包和发行检查自动失效；旧文件只保留历史，必须组装新包并重检。
- 只有 CUT、代理、参考导出、旧导出，或缺少 Master hash/Profile/组件绑定时，不得进入 v0.8 包装。
- 包装采用不等于检查通过；检查通过不等于发布授权；只有真实回执才能登记已发布。
