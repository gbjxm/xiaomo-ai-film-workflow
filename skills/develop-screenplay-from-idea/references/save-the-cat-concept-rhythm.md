# Snyder 模块：概念承诺与观众节奏

## 负责范围

本模块负责故事在观众层面的清晰度、吸引力与节奏承诺：

- 高概念与核心钩子
- 一句话故事
- 主角、目标、阻力和主要观看内容
- 类型承诺与“这个故事最好看的部分”
- 从开场意象到结尾意象的转变
- 15节拍的功能性检查

不负责替代人物深度、主题论证或场景内部冲突。

## 概念诊断

先回答：

1. 用一句话能否说清“这是什么故事”？
2. 谁主动追求什么？什么力量阻止他？
3. 一句话是否只讲建置，没有透露故事主体会持续观看什么？
4. 是否存在易理解的矛盾、反差、讽刺关系或强烈心理图像？
5. 概念是清楚而新鲜，还是只有题材、世界观和风格？
6. 观众从标题、海报或开场获得的承诺，正文是否兑现？

高概念不等于规模大。优先检查：

- 是否容易理解和转述
- 是否有鲜明钩子
- 是否触及基础而直接的人类欲望或恐惧
- 是否让两种通常分离的力量发生有意义的碰撞
- 是否能自然产生多个“只有这个故事才会有”的场面

## 一句话故事工作式

不要强迫固定句式，但至少识别：

```text
具有关键特征的主角
+ 触发行动的处境
+ 可观察的主要目标
+ 主要阻力或对立力量
+ 独特矛盾、代价或钩子
```

一句话故事不是宣传文案。先保证故事机制真实，再追求漂亮。

## 节奏诊断

把15节拍当作功能问题，不当作页码命令：

1. 开场意象：故事开始前的状态与基调是什么？
2. 主题提出：人物尚未理解的核心问题如何被触碰？
3. 建置：主角、世界、缺陷、欲望和风险是否足够清楚？
4. 催化剂：什么打破原有平衡？
5. 犹豫：为什么主角不能立刻顺利行动？
6. 进入新局面：什么选择让故事真正开始？
7. 辅助关系线：哪段关系承载主题或提供另一面？
8. 承诺兑现：观众因这个概念而来，正文给了哪些独有场面？
9. 中点：目标、压力、认知或风险怎样发生实质改变？
10. 压力逼近：外部和内部问题如何同时收紧？
11. 一切尽失：主角失去什么或误以为什么已经无法挽回？
12. 灵魂黑夜：失败迫使人物面对什么？
13. 进入终局：新认识如何产生新行动？
14. 终局：人物如何用行动解决外部问题并完成内在变化？
15. 结尾意象：它如何与开场形成可见对照？

短片可以合并多个节拍。不能因为时长短而删除催化、转向、升级和兑现这些功能。

## 通过标准

- 一句话能让不了解项目的人理解主体故事。
- 故事主体兑现概念承诺，而非只在开头展示设定。
- 节奏变化来自人物选择和压力升级。
- 开场与结尾能显示人物、关系或世界状态的变化。

## 常见误用

- 为满足15格而添加无因事件。
- 把高概念误解成昂贵奇观。
- 只优化推销语言，不修复故事机制。
- 用百分比机械切割6—10分钟短片。
