# 五书会诊协议

## 触发条件

用户表达以下意图时进入会诊模式：

- “这个版本已经不错了，帮我检查”
- “用五本书诊断一下”
- “看看还有什么不足”
- “整体框架无误，开始复盘”
- “修改后再检查一轮”

如果材料只有一句模糊点子，不执行完整会诊；继续发展模式。

## 会诊前准备

1. 明确诊断对象：一句话故事、大纲、分场或剧本正文。
2. 记录当前已确认、工作版本、开放和禁止改动的内容。
3. 确认作品时长、媒介、类型意图和AI生产限制。
4. 不因为理论检查自动改变用户已经确认的核心。

## 五个诊室

### 1. Snyder：概念与观众体验

检查：

- 一句话故事是否清楚、有钩子、包含主体故事
- 概念是否产生独有场面
- 类型与观众承诺是否兑现
- 节奏是否存在建立、触发、转向、升级、低谷和终局
- 开场与结尾是否形成转变

### 2. Egri：前提、人物与冲突

检查：

- 前提是否可由人物行为和结局检验
- 主要行动是否源于人物动机
- 对立意志是否坚定且互相排斥
- 人物是否被迫留在冲突中
- 冲突是否逐步升级到必然碰撞

### 3. Truby：故事系统

检查：

- 弱点、需要、欲望、对手、计划、斗争、自我认识和新平衡是否关联
- 对手和人物关系网是否产生情节
- 主题是否通过道德选择与后果呈现
- 世界、象征、揭示和情节是否服务同一故事
- 场景是否形成因果织体

### 4. Field：银幕宏观结构

检查：

- 开端是否及时建立人物、处境、前提和戏剧需求
- 主要行动是否进入清楚的发展阶段
- 关键转折是否改变行动方向
- 解决段是否回答核心戏剧问题
- 剧本是否通过可见、可听内容推进

### 5. McKee：场景、序列与高潮

检查：

- 场景是否有目标、对抗、期待—结果裂缝和价值变化
- 序列是否递进复杂化
- 重复场景是否只传递信息
- 危机是否要求有代价的选择
- 高潮是否既出人意料又符合因果，并产生核心意义

## 单项诊断格式

每本书必须输出：

```text
结论：成立 / 基本成立 / 薄弱 / 缺失 / 暂无证据
证据：引用当前材料中的具体情节、场景或空缺
后果：不修改会怎样影响观众、人物或结构
建议：一至三个修改方向
代价：会影响哪些已确认内容、时长和资产
优先级：阻断 / 高 / 中 / 低
```

不使用无依据的百分制。理论符合度不是作品质量分数。

## 跨书综合

完成五项后，把问题合并成三类：

1. 根因问题：一个修改可同时解决多个诊断，例如欲望线不清导致结构、节奏和场景都松散。
2. 局部问题：只影响一个场景、一次揭示或一处节奏。
3. 理论偏好：不同理论给出不同方向，但作品未必错误。

按以下顺序修复：

```text
前提与人物因果
→ 欲望线、对手与故事系统
→ 宏观转折
→ 场景与序列动力
→ 节奏优化和表达精修
```

## 反复诊断

1. 第一轮全诊断只找问题，不同时重写全部内容。
2. 用户选择一个高优先级问题后，回到发展模式局部修改。
3. 修改后只复查受影响模块。
4. 整体稳定后再执行一次完整会诊。
5. 两轮都没有新证据时，将相应层面标记为“暂定确认”，避免无休止推翻。
