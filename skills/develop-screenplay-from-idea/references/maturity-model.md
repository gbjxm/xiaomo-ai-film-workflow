## 用途

用六个独立维度判断“从一个点子到完整剧本”的成熟度。不要用单一字母概括尚未分别验证的知识、流程和效果。

整体达到某一级，必须六个维度全部达到该级门槛；单项较高不能抵消另一项不足。

## 六个维度

### 1. 来源忠实度

衡量编剧知识是否来自可靠、可追溯的具体版本。

| 等级 | 标准 |
|---|---|
| C | 主要依赖未核对的二手摘要或模型常识 |
| B | 已核对作者、方法官网、出版社资料或官方节选，但未覆盖完整书籍 |
| A | 已核对用户提供的具体完整版本；重要知识可追溯到章节和页码 |
| A+ | 已处理版本差异、翻译差异和跨书术语差异；所有关键主张均有来源状态 |
| S | 来源提炼可复现、可审计、可增量更新；发现冲突或误引时能定位并修正全部受影响知识 |

### 2. 知识操作化

衡量书中知识能否稳定转化为创作行动。

| 等级 | 标准 |
|---|---|
| C | 只有术语、简介或概念摘要 |
| B | 已形成模块、诊断问题、通过标准和常见误用 |
| A | 已形成原子知识卡；每张卡具有输入、生成、诊断、修改、禁用和AI短片适配规则 |
| A+ | 知识卡能组合工作，支持从模糊点子到局部改写的完整闭环 |
| S | 能依据跨项目验证结果调整适用条件，同时保持原作者观点与项目经验分离 |

### 3. 路由与治理

衡量 Skill 能否选择正确理论并处理冲突。

| 等级 | 标准 |
|---|---|
| C | 每次随意选择理论，或五本书同时堆叠 |
| B | 已定义五书职责、主辅路由和基本优先关系 |
| A | 已建立问题管辖权、术语对照、跨层影响和理论冲突裁决 |
| A+ | 能把重复意见合并为根因，区分结构缺陷、局部问题和理论偏好，并执行停止规则 |
| S | 路由在差异项目中经过验证；能够依据失败记录校准，同时禁止单个项目经验越权成为通用规则 |

### 4. 诊断与修改

衡量 Skill 是否能凭具体证据发现问题并提出最小有效修改。

| 等级 | 标准 |
|---|---|
| C | 主要给出通用建议或主观评价 |
| B | 已有五书会诊格式，能输出结论、证据、后果、建议、代价和优先级 |
| A | 能稳定找到问题所在层级，区分症状与根因，并生成机制上不同的修改候选 |
| A+ | 能识别“不是问题”“信息不足”和“理论偏好”，避免重复诊断与过度修改 |
| S | 在多个真实项目中具有可接受的误诊率；修改能稳定改善决策质量并减少返工 |

### 5. 测试与验证

衡量 Skill 的回答质量是否经过可重复检查。

| 等级 | 标准 |
|---|---|
| C | 只有文件、元数据和引用结构校验 |
| B | 有少量项目试验或示例，但没有统一评测集和基线 |
| A | 有成功、失败、模糊和不适用案例；每次修改执行行为回归 |
| A+ | 完成普通回答、旧版本和新版本的盲测或等价对照，且无关键能力回退 |
| S | 在至少三个差异明显的完整AI短片项目中验证，并有可追踪的生产结果和长期回归记录 |

### 6. 个人与AI生产适配

衡量 Skill 是否既适应用户创作方式，又能正确处理AI生产反馈。

| 等级 | 标准 |
|---|---|
| C | 只提供通用编剧建议，不区分生产问题 |
| B | 已有AI可制作性检查和反馈分类，但没有独立个人偏好层与完整生产记录 |
| A | 用户稳定偏好、项目事实和通用理论分层保存；能区分故事、场景、模型、提示词、资产、剪辑和声音问题 |
| A+ | 能把生成与粗剪反馈安全地返回相应创作层，只复查受影响模块 |
| S | 在三个差异项目中证明能够吸收有效经验、拒绝错误归因，并在收益不足时停止修改 |

## 当前基线

评定日期：2026-07-06。

| 维度 | 当前等级 | 直接证据 | 主要缺口 | 升至A的条件 |
|---|---|---|---|---|
| 来源忠实度 | B | 五书索引已登记官方作者、方法和出版社来源 | 没有用户提供的完整具体版本、章节与页码映射 | 逐本完成版本登记、章节来源地图和重要主张定位 |
| 知识操作化 | B | 五本书均有独立模块、诊断问题、通过标准和误用提示 | 没有逐章提炼的原子知识卡，覆盖范围有限 | 每本书建立可追溯知识卡并覆盖生成、诊断和修改 |
| 路由与治理 | B | 已有五书分工、主辅路由和人物因果优先原则 | 没有完整术语对照、冲突裁决表、根因图和停止协议验证 | 完成跨书治理接口并通过冲突案例 |
| 诊断与修改 | B | 已有五书会诊和证据—后果—建议格式 | 尚未证明能稳定区分症状、根因、风格选择和非问题 | 用统一案例验证分层诊断与最小修改 |
| 测试与验证 | C | 已通过 Skill 结构、元数据和直接引用校验；仅有《旧壳》局部试验 | 没有评测集、基线回答、行为回归和盲测 | 建立《旧壳》加小型案例的评测集并持续回归 |
| 个人与AI生产适配 | B | 已有AI短片适配和生成、粗剪反馈分类 | 没有独立个人偏好协议、真实生产反馈记录和跨项目验证 | 分层保存偏好并建立完整生产问题分类与回写证据 |

当前结论：这是一个具备专业结构的 **B级原型**，其中测试与验证仍处于 C。该结论不是五本书内容质量的平均分，也不能写成“整体B+”。

## 整体晋级门槛

### A级

必须同时满足：

- 六个维度全部达到 A。
- 五本书均完成具体版本核对、知识卡、集成和回归。
- 重要专业判断可追溯。
- 生成、诊断和修改三类能力均通过《旧壳》与小型案例。

### A+级

必须先达到 A，并同时满足：

- 完成跨书术语对照、分权治理、冲突裁决、根因合并和停止规则。
- 建立独立个人偏好层。
- 完成普通回答、旧版和新版的盲测或等价对照。
- 能保护非传统结构，识别信息不足、理论偏好和无需修改。

### S级

必须先达到 A+，并同时满足：

- 完成《旧壳》和另外两个差异明显的AI短片项目闭环。
- 保存理论建议、用户选择、生产结果、误诊、失败和有效经验。
- 证明能区分故事与模型、提示词、资产、剪辑、声音问题。
- 证明相较A+版本稳定提高决策质量并减少返工。
- 经验晋升有跨项目证据，且具备停止修改能力。

## 评定规则

1. 每个目标只更新有新证据的维度。
2. 不因新增文档自动升级；必须满足该等级的验收条件。
3. 单本书达到 A，只提升对应来源和知识项，不代表整个 Skill 达到 A。
4. 每次晋级记录证据、未满足条件和下一目标。
5. 缺少行为或项目验证时，等级不得依据主观印象上调。
