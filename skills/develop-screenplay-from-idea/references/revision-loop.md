# 生成与粗剪反馈修改协议

## 原则

把生成结果和粗剪当作新证据，不把它们当作必须服从的答案。

## 1. 先定位问题

区分：

- 故事问题：因果、目标、人物选择或结局本身不成立
- 场景问题：场景没有变化、信息重复或冲突不足
- 表达问题：剧本文字没有把意图转成可见行动
- 模型问题：当前生成能力无法稳定完成
- 提示词问题：创作规格正确，但翻译或约束不足
- 剪辑问题：素材顺序、时长、节奏或声音关系造成误读

不要用重写剧本解决模型或提示词问题。

## 2. 判断影响范围

- 局部：一句动作、一个场景或一个连接
- 段落：一个序列的顺序或目标
- 全局：人物弧线、核心前提或结局

优先采用能够解决根因的最小修改。

## 3. 重开内容

记录：

- 什么新证据导致重开
- 原版本试图完成什么
- 哪部分保留
- 哪部分修改
- 对下游资产和已生成素材有什么影响

## 4. 修改后验证

只检查本轮目标，不在同一轮顺手重写所有层级。

验证问题示例：

- 观众是否能理解这一选择
- 误导是否公平
- 铺垫是否足以支持高潮
- 新场景是否真的增加变化
- 替代动作是否保留人物意义

## 5. 写回

保存修改后的工作状态、采用理由和仍未解决的问题。不要把整段专业知识或所有失败版本复制进主剧本。
