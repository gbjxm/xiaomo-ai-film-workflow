# C1｜美术与资产工作稿入口

回到 [项目入口](../../../开始这里.md) 读取共享能力；正式对象索引在 [C_视觉生成.md](../../../C_视觉生成.md)。本入口只导航专业工作；工作集状态和保存由 studio_runtime 管理。

依据 C2 前期导演意图，按需调用资产与配色专业，设计人物、场景几何、材料和状态；区分基础资产、状态资产与镜头参考，返回完整资产候选及参考职责。

先核对项目能力；开启后用 List/Inspect 定位本次 C1 工作集，读取其 required_read_set、完整稿与依赖差量。每个 key 独立保存到 90_制作资料/工作稿/C1/<key>/，对应 state 位于 .工作室/工作集/<key>/state.json，短缓存为 90_制作资料/续接缓存/<key>.json；这些路径均相对项目根。

完整稿变化用 SaveDraft，用户明确采用精确版本后由所属专业通过 Adopt 提交文本。共享已采用内容先 Resolve 再读取不可变快照；普通 Markdown 只是视图。缓存丢坏走 Inspect；采用中断走 ResumeSync，区分未提交、已采用待同步和历史提交，保留未知手改。

用户明确要求新任务或续接时，使用 PrepareHandoff → 创建任务 → ActivateHandoff；创建失败 CancelHandoff。不读取维护 HANDOFF 或旧单岗缓存，不因保存候选自动分配影视 ID。第一批能力关闭时仅保留演练决定。
