# 小陌 AI 影视工作流 V1｜个人 AI 影视工作室

> 产品版本 1.0；项目入口显式声明 workflowRelease: 1.0，并沿用 workflowStudio: studio-v0.9 协议和现有运行时 schema。无发布标识的旧项目保持原分支。机器安装不代表旧项目迁移；无标识项目保留原流程。

## 作品与组织

面向一部影片组织专业工作：先确定观众要看懂什么、体验什么，以及如何在现有时间、费用与工具条件下完成，再进入资产和镜头生产。用户保留创作决定。V1 图片在明确执行请求、充分输入和实际工具可用时默认调用 Codex 原生能力；视频与发布保持既有授权方式；D 默认通过经实际核验、获得本次执行授权的达芬奇后台原生接口完成后期，也可按用户当次选择接回手工结果。

| 部门 | 核心判断 |
| --- | --- |
| A 制片统筹 | 作品目标、资源、依赖、进度与里程碑 |
| B 编剧开发 | 人物、行动因果、剧情与对白 |
| C1 美术与资产 | 视觉世界、角色、场景几何、材料与状态 |
| C2 导演与视听制作 | 从前期贯穿整片的观众体验、调度、表演、摄影灯光与节奏 |
| D 剪辑与声音后期 | 前期接口、真实组接、声音与影片完成、QC |
| E 发行与复盘 | 包装、资格、发行证据与反馈 |

部门是责任，任务是工作上下文，记录是共同事实。保留 A/B/C/D/E 正式主文件；C1/C2 是 C 内部标签，有各自工作稿入口。图片按专业用途归属：角色设定归 C1，分镜与镜头关键帧归 C2。活动 Skill 以 manifest 为准，当前 23 个。`organize-ai-film-media` 为 C/D 共用的生成视频整理与查找工具，不新增部门，不接管专业判断。

D 保持 `edit-and-finish-ai-film` 一个主入口与原有文件所有权。`grade-film-in-resolve` 是其专业调色子能力，`davinci-resolve-mcp` 是技术接口；专项能力不新增部门、不另建正式状态、不创造 CUT。默认在同一达芬奇原生工程中持续调整用户指定的一版，明确要求测试时才保留原版与三个候选。专业判断遵循输入/色彩管理、影片意图、基础匹配、风格与必要局部、按需质感、动态复看及原生导出回读，不固定风格或参数、不每镜强制全套操作。

## 一轮完整设计

1. A 整理制作约束，B 提供故事，C2 在资产定稿前提炼整片创意与视听基准。
2. C2 按问题联合 C1、表演、摄影及 D 剪辑声音意见；需要剧情调整时请 B 提候选差量。新片段主动检索实际相关知识、条件和反例。
3. 空间、动作与摄影依赖对齐后形成逐镜整案；格式器忠实编排完整候选，不要求用户逐专业采用。
4. 独立审查根据原始需求和完整稿复述可见事件链，定位问题并定点修正，交一份完整、可修改的方案与候选提示词。
5. 用户统一审阅。高影响未知以后续少量真实试样验证，记录结果、耗时与费用；实际生成、组接不能由文本检查替代。

## 保存、恢复与验证边界

当前模板声明 runtime_schema=xiaomo.studio-runtime/v1，candidate_design、workset_runtime 与 adoption_transactions 为 true，media_execution 为 false。这里的 media_execution 指工作室运行时内置媒体功能，不因达芬奇接入全局开启。独立达芬奇原生 API/MCP 须实际可用并有本次用户执行授权，后台操作不占键鼠；不据安装宣称全部 API 可控或影片效果已通过，也不默认改走外部 FFmpeg 调色。能力仍为 false/false 的早期隔离演练项目仅支持候选设计，不自动升级。

每个工作集独立持有租约、完整候选及短缓存；SaveDraft 保存完整稿，Inspect 从 state 与不可变快照恢复。C1/C2 可各有多个工作集。用户明确采用后，所属专业文本经 Adopt 统一发布；.工作室/采用索引.json 是唯一原子采用发布点，普通 Markdown 是可重建视图，消费采用内容先 Resolve。

恢复区分尚未采用、已完整采用但视图待同步、已被后续版本替代；ResumeSync 接续原事务，未知手改保留。只有用户明确要求新开/续接才创建任务，PrepareHandoff/ActivateHandoff/CancelHandoff 管理租约转移；不预建六任务，不把旧单 C 缓存当作新运行时。日常工作不读取维护 HANDOFF。

工作集、对象冲突、采用和恢复按软件验收记录判断；能力字段不替代测试证据。真实生成、组接、耗时和费用由每个项目的实际结果验证。安装和指定项目接入分别保留恢复点；未验证的媒体效果不能在版本晋升时被标为通过。

正式制作仍沿用 S/A/V/CUT/PUB；Setup、take、四组件与 Master 保持原语义。CUT、Lock、Master/QC、精确发行包分别需要真实证据。未验证功能不写成完成，候选文件存在不代表正式记录已经保存。

调色工作稿、原生工程保存和真实导出与正式采用分开。用户正式采用后由 D 更新相应 PIC/调色指针及实际受影响的 Master/QC 依赖；独立达芬奇授权不迁移旧项目、不扩大视频生成、上传或公开发布权限；V1 原生图片执行单独遵守共同契约，确认方案不自动生成。

## V1 最小整合边界

保留当前六部门与23技能、完整候选和理由交接、局部修改及真实证据分层。日常专业步骤不新增 A 审批，普通未变材料复用；写入并发保护、必要专业检查和实际制作授权不因减少中断而省略。V1 独立图片动作见共同契约“V1 原生图片工具”；文本运行时仍不执行媒体。

各岗位的软件与文字验收不构成连续创作或整片效果证明。A 正常衔接临时方法及其他未采用候选不自动并入，E 专项无完成证据不称已验收；具体项目的暂停选择以当前项目材料为准。
